# 数字人口播与直播工作台

- id：`workbench-digital-human`
- 分类：数字人
- 类型：workbench
- 入口路由：`/workbenches/digital-human`

文稿或 LLM 输出交给数字人念出来：离线出成片，或起一路实时会话做直播与教课。

把文稿或 LLM 输出交给数字人念出来：离线渲染出成片用于口播视频，或起一路实时会话让数字人直播带课，形象与音色都可按品牌配置。

## 安装

```bash
npm run tcsol -- install workbench-digital-human
```

qiye-app 中按 id `workbench-digital-human` 或名称「数字人口播与直播工作台」安装；已安装后随方案仓库发布自动升级，用户数据（`digital-human/`）不受影响。

## 宿主依赖

本方案代码引用了 7 个宿主模块、8 个 npm 包，明细见 `origin.json`。
