# 研发工作流 更新日志

## 2.0.2 (2026-10-23)

- 界面样式改用宿主设计 token（圆角 / 字号 / 主色等随主题统一，同步 qiye-app master 的界面改造）；需要 App 2.0.6 起（更早的 App 继续用上一版）。

## 2.0.1

- 修复：英文 / 阿拉伯语界面下，工作流各节点提示词里的项目名、需求、产出目录、上游结果被翻译吃成空（节点拿不到需求，产出路径变成「$/$/」）。
- 修复：启动失败（如没配模型）时，产出历史里那条记录一直停在「执行中」。
- 界面随语言方向（阿拉伯语从右到左）；代码 diff 始终左到右。
- 方案入口导出 deactivate：宿主卸载 / 停用 / 升级时按统一流程释放（本方案没有后台任务，行为不变）。
- 修复：主进程里按需加载的宿主模块 / npm 包（文档解析、邮件收发、PDF 等）运行时加载失败 —— 动态 import 改为经宿主模块注册表取得。

## 2.0.0

- 改为动态方案（runtime.mode=dynamic，hostApi=2）：界面与主进程逻辑来自方案包，不再随 App 编译；升级在重启后生效。
- 共用代码（被宿主或多个方案使用的部分）移入宿主 SDK，由宿主模块注册表提供。
- 上一版本：1.0.0（随 App 构建）。
