# 短视频创作与发布工作台

- id：`embedded-video-studio`
- 分类：内置
- 类型：workbench
- 入口路由：`/video-studio`

从素材整理、脚本、配音配乐到成片审核，一次准备抖音、快手、小红书和微信视频号版本。

从素材整理、脚本撰写、配音配乐到成片审核一条流水线，一次制作即可同时准备好抖音、快手、小红书与微信视频号四个平台的版本与文案。

## 安装

```bash
npm run tcsol -- install embedded-video-studio
```

qiye-app 中按 id `embedded-video-studio` 或名称「短视频创作与发布工作台」安装；已安装后随方案仓库发布自动升级，用户数据（无本地数据目录）不受影响。

## 宿主依赖

本方案代码引用了 14 个宿主模块、5 个 npm 包，明细见 `origin.json`。
