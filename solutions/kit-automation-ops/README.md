# 自动化运营控制台

- id：`kit-automation-ops`
- 分类：内置组件
- 类型：kit

智慧医院 / 产销存工作台共用的自动化场景控制台、执行结果与演示场景。



## 安装

```bash
npm run tcsol -- install kit-automation-ops
```

qiye-app 中按 id `kit-automation-ops` 或名称「自动化运营控制台」安装；已安装后随方案仓库发布自动升级，用户数据（无本地数据目录）不受影响。

## 宿主依赖

本方案代码引用了 5 个宿主模块、3 个 npm 包，明细见 `origin.json`。
