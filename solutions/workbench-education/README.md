# 职教与高校工作台

- id：`workbench-education`
- 分类：教育
- 类型：workbench
- 入口路由：`/workbenches/education`

多 Agent 协同备课、实训辅导、学情分析、教学配图与教师审核。

面向职教与高校的多 Agent 教学协同：备课组联合产出教案与实训指导，学情分析自动汇总班级薄弱点，教学配图按知识点生成，所有产出经教师审核后才进入课堂。

## 安装

```bash
npm run tcsol -- install workbench-education
```

qiye-app 中按 id `workbench-education` 或名称「职教与高校工作台」安装；已安装后随方案仓库发布自动升级，用户数据（无本地数据目录）不受影响。

本方案代码引用了 8 个宿主模块、8 个 npm 包，明细见 `origin.json`。
