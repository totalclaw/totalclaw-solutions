# 全平台运营

- id：`oneclick-video`
- 分类：全媒体运营
- 类型：runner（runner `oneclick-video`）

选一个素材文件夹，一键跑完整条全平台运营：自动写文案 → 合成 9:16 竖屏短视频（Ken Burns 运镜+转场）→ 客资 RFM 分层+回访话术 → 中差评回复 → 数据复盘(ROI/复购/漏斗) → 同城获客方案 → 汇总成运营简报。可选一键发布到 小红书/抖音/视频号（发布会停在登录页等你扫码登录，不会因没登录就失败）。

## 安装

```bash
npm run tcsol -- install oneclick-video
```

运行记录保存在账号目录 `solution-runs.json`（按方案 id 分组），升级不影响。
