# 项目工作台 更新日志

## 2.0.3 (2026-10-28)

- 界面样式：剩余写死的颜色 / 圆角 / 阴影 / 字号改用宿主设计 token，图标去掉 sparkle / emoji，深色强调面按界面主题取色。
- 按钮交互状态：禁用的按钮悬停不再变色，选中 / 展开态不被悬停覆盖。
- 越南语 / 马来语界面：语言判定修正；只备了中英阿的内容（报告、规则来源与税务输出译文、默认输出语言）回落英文。
- 品牌名称统一取宿主品牌入口。

## 2.0.2 (2026-10-22)

- 界面样式改用宿主设计 token（同步 qiye-app master 的界面改造）；需要 App 2.0.6 起。
- 能力卡片标题随品牌显示（白标版不再写死 TotalClaw）（同步 qiye-app yitiji 分支的品牌统一改动）。
- 需要 App 2.0.6 起（宿主模块注册表新增 renderer/utils/brand.ts）；更早的 App 继续使用 2.0.1。

## 2.0.1

- 英文 / 阿拉伯语界面：负责人、审计记录里带参数的内置文案按当前语言显示。
- 英文 / 阿拉伯语界面：演示案例（名称、文件、BOQ、符合性、风险、证据摘录等）按当前语言显示；用户录入的内容原样显示。
- 方案入口导出 deactivate：宿主卸载 / 停用 / 升级时按统一流程释放（本方案没有后台任务，行为不变）。
- 修复：主进程里按需加载的宿主模块 / npm 包（文档解析、邮件收发、PDF 等）运行时加载失败 —— 动态 import 改为经宿主模块注册表取得。

## 2.0.0

- 共用代码（被宿主或多个方案使用的部分）移入宿主 SDK，由宿主模块注册表提供。
- 上一版本：1.0.0（随 App 构建）。
