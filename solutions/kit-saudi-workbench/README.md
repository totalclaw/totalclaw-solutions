# 沙特数字员工底座

- id：`kit-saudi-workbench`
- 分类：内置组件
- 类型：kit

rfq-quote / bid-decision / advisory-report 三个数字员工共用的统一收件 + 三栏工作台底座与案件存储。



## 安装

```bash
npm run tcsol -- install kit-saudi-workbench
```

qiye-app 中按 id `kit-saudi-workbench` 或名称「沙特数字员工底座」安装；已安装后随方案仓库发布自动升级，用户数据（`totalclaw-agent/cases/case-store.json`、`totalclaw-agent/saudi/data-pack.json`）不受影响。

本方案代码引用了 11 个宿主模块、15 个 npm 包，明细见 `origin.json`。
