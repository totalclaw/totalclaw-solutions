# STEP6 · 账务风险检测（内置风控规则）

**角色**:对本期凭证 + 期末汇总做风险扫描,输出风险清单(等级+依据+建议)。只提示,不改账。

## 输入

STEP4 凭证 + STEP5 报表数据 + 汇总:
```json
{"会计期间":"2026-06","银行账面余额":88700,"银行流水期末余额":88700,
 "库存商品期末":110000,"库存现金期末":500,
 "销售收入":500000,"开票金额":520000,"销项税额":65000,"进项税额":40000,"应纳增值税":25000,
 "主营业务成本":300000,"毛利率":0.40,
 "业务招待费":8000,"职工福利费":12000,"广告宣传费":0,"工资总额":64000,
 "其他应收款_股东":150000,"股东往来账龄天数":400,"现金大额收支笔数":1,
 "行业":"商品批发","纳税人类型":"一般纳税人"}
```

## 风控规则（命中即报）

| # | 风险点 | 判定 | 等级 |
|---|---|---|---|
| 1 | 银行账面≠流水余额 | 银行存款账面余额 ≠ 流水期末余额 | 高 |
| 2 | 现金负数 | 库存现金期末 < 0(不可能为负) | 高 |
| 3 | 库存商品负数 | 库存商品期末 < 0(卖了没进货) | 高 |
| 4 | 招待费超限 | > min(发生额×60%, 营收×0.5%) 部分需纳调 | 中 |
| 5 | 福利费超限 | > 工资总额×14% | 中 |
| 6 | 股东大额长期挂账 | 「其他应收款—股东」大额且账龄长 → 视同分红 20% 个税 | 高 |
| 7 | 收入<开票 | 申报收入 < 开票金额 | 高 |
| 8 | 增值税税负率异常 | 应纳增值税/销售收入 明显低于行业预警值 | 高 |
| 9 | 进销品名背离 | 采购与销售货物不匹配(三流不一致) | 高 |
| 10 | 白条列支 | 无正规发票列支成本(见 STEP4 `⚠️无票`) | 中 |
| 11 | 毛利率异常 | 大幅偏离行业或环比突变 | 中 |
| 12 | 广告费超限 | > 营收×15%(部分行业30%) | 低 |
| 13 | 社保/个税与工资不匹配 | 社保基数、个税与工资总额严重不符 | 中 |
| 14 | 进项认证超期 | 专票开票 > 360 天未认证 | 中 |
| 15 | 印花税漏缴 | 有购销合同未计提印花税 | 低 |

阈值(行业税负率、扣除比例、小微门槛)随政策变;命中时给**具体金额与调整方向**,拿不准写「按最新税法/主管税务机关口径核实」,不编造精确阈值。

## 输出 JSON schema

```json
{"会计期间":"2026-06",
 "风险":[
   {"编号":1,"风险点":"银行账面≠流水余额","等级":"高","依据":"账面 88,700 与流水期末 88,700 一致→通过;若不一致给出差额","建议":"逐笔核对未达账项"},
   {"编号":4,"风险点":"业务招待费超限","等级":"中","依据":"招待费8,000;可扣=min(8000×60%=4800,500000×0.5%=2500)=2500","建议":"汇算纳税调增5,500"}
 ],
 "高风险数":0,"中风险数":1,"低风险数":0,
 "结论":"本期存在1项中风险,建议汇算时处理招待费调整"}
```

## 边界

只提示不改账;阈值拿不准写「需按最新税法核实」,不编造;所有处理由会计判断。
