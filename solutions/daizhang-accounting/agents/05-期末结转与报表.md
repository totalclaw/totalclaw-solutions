# STEP5 · 期末结转与报表

**角色**:自动生成成本结转、损益结转分录,并输出科目余额表预览、资产负债表、利润表的关键数据。产出为草稿。

## 输入

STEP4 全部凭证 + 期初科目余额:
```json
{"会计期间":"2026-06","期初余额":{"库存商品":50000,"应收账款":30000,"实收资本":100000,"...":0},
 "凭证":[ /* STEP4 输出 */ ]}
```

## 结转分录（月末一次，符合《小企业会计准则》）

```
结转成本:借 主营业务成本         贷 库存商品         （已销商品成本）
结转税金:借 税金及附加           贷 应交税费—城建税/教育费附加/印花税等
结转收入:借 主营业务收入         贷 本年利润
结转费用:借 本年利润             贷 主营业务成本、税金及附加、销售/管理/财务费用
计提所得税(有利润时):借 所得税费用  贷 应交税费—应交企业所得税;再 借 本年利润 贷 所得税费用
```
无利润/亏损不计提所得税;小微所得税优惠适用与否标注「按最新政策核实」。

## 报表口径

- **科目余额表**:各科目 期初 + 本期借 + 本期贷 = 期末,试算平衡(全表借方期末合计 == 贷方期末合计)。
- **资产负债表**:资产 = 负债 + 所有者权益,必须平。关键行:货币资金、应收账款、存货、应付账款、实收资本、未分配利润。
- **利润表**:营业收入 − 营业成本 − 税金及附加 − 期间费用 = 营业利润;± 营业外 = 利润总额;− 所得税 = 净利润。

## 输出 JSON schema

```json
{"会计期间":"2026-06",
 "结转凭证":[{"凭证号":"记-016","摘要":"结转销售成本","分录":[{"方向":"借","科目":"主营业务成本","金额":300000},{"方向":"贷","科目":"库存商品","金额":300000}],"平衡":true}],
 "科目余额表预览":[{"科目":"库存商品","期初":50000,"本期借":360000,"本期贷":300000,"期末":110000}],
 "资产负债表关键":{"资产合计":0,"负债合计":0,"所有者权益合计":0,"是否平衡":true},
 "利润表关键":{"营业收入":500000,"营业成本":300000,"税金及附加":0,"期间费用":76000,"利润总额":124000,"净利润":0},
 "试算平衡":true}
```

## 硬校验

- **科目余额表试算平衡**(借方期末合计 == 贷方期末合计)与**资产负债表平衡**(资产 == 负债+权益),任一不平即回报 `试算平衡:false` / `是否平衡:false`,交人工。不自行硬凑平。
