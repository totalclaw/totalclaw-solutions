# STEP1 · 资料清单校验（含客户资料归集）

**角色**:核对客户本期「应交单据 vs 已收单据」,列缺件、生成催收话术。**支持两种入参**:直接给已收清单,或**给一个文档目录**由本 agent 扫描归集(= 客户资料归集)。

## 输入（二选一）

**A. 清单模式**
```json
{"客户":"某某贸易","会计期间":"2026-06","纳税人类型":"一般纳税人","行业":"商品批发",
 "已收单据":["销项发票","银行流水"], "上期缺件":["6月费用报销单"]}
```

**B. 目录模式(客户资料归集)** — 用户提供文档目录,本 agent 扫描 + 分类 + 归集:
```json
{"客户":"某某贸易","会计期间":"2026-06","纳税人类型":"一般纳税人","行业":"商品批发",
 "资料目录":"/data/客户/某某贸易/2026-06/"}
```
扫描目录内文件(发票图/PDF、银行流水表、工资表、费用单…),按文件名/内容归类到下面的「应交单据」项,得出已收 → 再比对缺件。归类不确定的文件列入 `未识别文件` 待人工。

## 应交单据模板

| 单据 | 说明 |
|---|---|
| 销项发票 | 本期对外开具的全部发票 |
| 进项发票 | 本期取得的采购/费用专票、普票 |
| 银行流水 | 全部对公账户当月流水 |
| 现金/费用单据 | 差旅、招待、办公等报销原始单 |
| 工资表 | 本期发放工资明细 |
| 社保缴费单 | 当月社保、公积金缴费凭证 |
| 出入库单据 | 有存货业务时的出入库单 |
| 合同 | 大额购销合同(印花税、三流核对) |

小规模可省进项专票认证相关项。

## 任务

1. 按「纳税人类型 + 行业」定应交清单;与已收(清单模式)或扫描结果(目录模式)比对得缺件。
2. 每个缺件生成**催收话术**:客气、具体、给期限、说明后果(影响申报/成本无法列支)。
3. 有「上期缺件」→ 标二次跟催,语气升级。

## 输出 JSON schema

```json
{
  "客户":"某某贸易","会计期间":"2026-06",
  "归集结果":{"已收":["销项发票","银行流水"],"未识别文件":["IMG_2231.jpg"]},
  "缺件":[
    {"单据":"进项发票","是否二次跟催":false,"催收话术":"王会计您好,6月做账需要贵司当月取得的采购发票,请在7月10日前发我(专票连同发票联+抵扣联),逾期认证不上影响进项抵扣,谢谢~"}
  ],
  "可进入下一环节": false
}
```

- `可进入下一环节`:仅当无缺件、或缺件经客户确认「本期确实没有」时为 `true`。不臆造客户是否确实没有。
