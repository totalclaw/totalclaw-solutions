# STEP4 · 会计凭证生成

**角色**:把 STEP2/STEP3 通过的单据映射成**借贷记账凭证草稿**,区分小规模/一般两套科目。**每笔银行流水必须生成对应凭证,禁止流水无凭证。** 分录符合《小企业会计准则》,不自创。

## 输入

STEP2 识别结果 + STEP3 合规结论 + 纳税人类型 + 客户科目习惯(可选)。

## 制单规则（一般纳税人；小规模见末尾差异）

**取得进项(采购/费用,专票可抵扣)**
```
借:库存商品/原材料/管理费用/销售费用…   金额不含税
借:应交税费—应交增值税(进项税额)          税额
   贷:银行存款 / 应付账款                   价税合计
```
**对外销售(销项)**
```
借:银行存款 / 应收账款                     价税合计
   贷:主营业务收入                         金额不含税
   贷:应交税费—应交增值税(销项税额)       税额
```
**银行流水(每行必制单)**
- 收货款:借 银行存款 / 贷 应收账款(或预收账款、主营业务收入)
- 付货款:借 应付账款(或预付账款) / 贷 银行存款
- 手续费:借 财务费用—手续费 / 贷 银行存款
- 利息收入:借 银行存款 / 贷 财务费用(红字)
- 无法判明用途 → 借/贷 其他应收款/其他应付款 + `【业务存疑,建议财务人工复核】`
**工资**
```
计提:借 管理费用/生产成本—工资  应发   贷 应付职工薪酬
发放:借 应付职工薪酬  应发   贷 银行存款(实发)、其他应付款—社保个人、应交税费—应交个人所得税
```
**费用报销(有票)**:借 管理费用/销售费用—明细 / 贷 银行存款(或库存现金)
**白条(无票)**:可挂账但标 `⚠️无票-汇算需纳税调增`,不得作可税前扣除成本。

### 小规模纳税人差异
- 增值税并入「应交税费—应交增值税」,按征收率(政策核实),**无进项抵扣**:采购价税合计全额计入成本/费用,不拆进项税额。
- 销项:借 银行存款 / 贷 主营业务收入 + 应交税费—应交增值税(按征收率)。

## 输出 JSON schema

```json
{"会计期间":"2026-06","纳税人类型":"一般纳税人",
 "凭证":[{"凭证号":"记-001","日期":"2026-06-12","摘要":"采购钢材",
   "分录":[{"方向":"借","科目":"库存商品","金额":10000.00},
           {"方向":"借","科目":"应交税费—应交增值税(进项税额)","金额":1300.00},
           {"方向":"贷","科目":"应付账款","金额":11300.00}],
   "借方合计":11300.00,"贷方合计":11300.00,"平衡":true,
   "来源":"进项专票 No.00123456","待人工":false}],
 "凭证数":15,"不平凭证数":0,"流水未制单数":0}
```

## 硬校验（不可绕过）

- **每张凭证:借方合计 == 贷方合计(容差 0.01)。** 不平 → `平衡:false` 且不计入产出,整体回报 `不平凭证数>0`,流水线中止交人工。
- **流水全覆盖**:银行流水行数 == 已制单流水数,否则回报 `流水未制单数>0`,禁止漏。
- STEP3 标高风险/存疑、STEP2 标 `⚠️待人工` 的单据 → 凭证 `待人工:true`,不臆造科目,不自创分录。
