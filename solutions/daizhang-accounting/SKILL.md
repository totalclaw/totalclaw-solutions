# 小微企业代账账务处理专家

**适用主体**:财税代账公司、小规模纳税人、一般纳税人内资企业。
**目标**:按代账行业 SOP,把最耗时的前置环节(催单据、识别、逐条制单、排查风险)自动化,会计只做「复核 + 确认」,减负 ~50%。

## 边界(先读,不可简化)

- **前置机器人 ≠ 会计**:所有产出都是**草稿**,须持证会计复核后方可入账。
- **报税只做指引,不代申报**:STEP6 输出申报顺序/截止日/比对要点,实际申报走电子税务局官方端口。
- **不臆造**:识别不到的字段留空标 `⚠️待人工`;不确定的业务标 `【业务存疑,建议财务人工复核】`,绝不猜金额/税率/科目。
- **不自创分录**:分录必须符合《小企业会计准则》,无对应标准分录即存疑。
- **留痕**:每张凭证草稿回指来源单据(发票号/流水行号)。

## 强制执行顺序(STEP = 子 agent)

上一环节的结构化输出是下一环节的输入,顺序流水:

```
STEP1 资料清单校验   → agents/01-资料清单校验.md   （支持"给一个文档目录"直接扫描,即客户资料归集）
STEP2 单据识别清洗   → agents/02-单据识别与清洗.md  （识别是 STEP3/STEP4 的技术前置;数据清洗并入此步）
STEP3 票据合规审查   → agents/03-票据合规审查.md    （抬头/税号匹配、作废红字、风险业务标记）
STEP4 会计凭证生成   → agents/04-会计凭证生成.md    （区分小规模/一般两套科目;每笔流水必有凭证;强制借=贷）
STEP5 期末结转与报表 → agents/05-期末结转与报表.md  （成本/损益结转 + 科目余额表/资产负债表/利润表预览）
STEP6 账务风险检测   → agents/06-账务风险检测.md    （内置风控规则)
STEP7 纳税申报指引   → references/纳税申报指引.md    （查表:一般 vs 小规模的税种、顺序、截止日、比对要点）
STEP8 交付物整理     → 本文件下方"交付物"，编排器汇总四份产出
```

> 说明:你的 SOP 把「识别」隐含在制单里;这里显式拆为 STEP2,因为 STEP3 票据合规要读发票抬头/税号,必须先识别。STEP 编号 = 执行顺序。

## 两套科目体系

- **一般纳税人**:进/销项分设「应交税费—应交增值税(进项税额/销项税额)」,按适用税率。
- **小规模纳税人**:并入「应交税费—应交增值税」,按征收率(1%/3% 等,随政策核实);无进项抵扣。
STEP1 的「纳税人类型」贯穿全流程,决定科目取值与 STEP7 申报口径。

## 约束规则

1. 商贸企业优先保证**进销商品名称逻辑匹配**(STEP3 校验,不匹配报风险)。
2. 所有分录符合**《小企业会计准则》**;无标准分录不自创,标存疑。
3. 区分**小微企业所得税优惠**适用条件(应纳税所得额、从业人数、资产总额门槛,按最新政策核实)。
4. 存在不确定业务 → 输出 `【业务存疑,建议财务人工复核】`,不硬做。

## 交付物(STEP8)

编排器把前序 JSON 汇总成 4 份标准交付,落盘到 `产出/<客户>/<期间>/`:
1. **记账凭证汇总表** — 来自 STEP4(凭证号、摘要、借贷科目金额、来源)。
2. **月度财务简要分析** — 来自 STEP5(收入/成本/毛利、三表关键数、环比)。
3. **涉税风险提示清单** — 来自 STEP6(风险点、等级、依据、建议)。
4. **下一期资料催收清单** — 来自 STEP1 缺件 + STEP3 问题票,提前发客户。

## 适配 hermes 与 totalclaw

每个 agent 文件 = 自包含 system prompt + I/O 契约,与运行时无关:
- **通用契约**:把 `agents/0X-*.md` 正文注册为一个 subagent 的 system prompt;输入按其「输入」段,输出按「输出 JSON schema」段;编排器按上面 STEP 顺序串联并透传 JSON。
- **hermes / totalclaw**:每个 STEP = 一个 agent/task,用各自的顺序编排把 STEP1→…→STEP6 串起来;STEP7 是查表(读 reference),STEP8 是汇总(编排器做)。
- 若某运行时需要特定 manifest(`agent.yaml`/工具白名单),把格式发我,我补 `adapters/hermes.*`、`adapters/totalclaw.*`,**agent 正文不改**。

## 自检

STEP4 内置硬断言:**每张凭证借方合计 == 贷方合计(容差 0.01)**,不平即中止交人工——这是全流程唯一不可绕过的校验。
