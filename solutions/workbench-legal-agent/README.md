# 法务部 · 合同审查（workbench-legal-agent）

法务部（`legion-legal`）的工作台。七步向导，右侧原文随点随定位高亮。

## 可信性规则

- **位置由程序定**：模型只给原文原话，程序在段落里找（忽略空白与全半角）；找不到的条款和风险直接丢弃。跨段引用回到起始段；只能用开头 16 字定位到的标「位置近似」。
- **法条格式核对**：法律名称必须在 `resources/statutes.json`（34 部常用法律）里，条号不能超出该法条数，不合格的引用丢弃。通过只代表格式可信，**条文内容没有核对**，界面和意见书都写明。
- **金额 / 主体 / 期限**：只收原文里真的出现的内容。
- **缺失条款**：模板必备条款 − 已抽到的类别（程序算），再并上模型补充的合法类别。
- **风险指数**：100 起扣，高 15、中 6、低 2、缺失 3（程序算）。

## 导出

- 修订稿：原文逐段重排成新 Word（保留文字，不保留原格式），采纳的修订写成 Word 修订痕迹（删除 / 插入）与批注，可在 Word 里逐条接受或拒绝。同一段内位置重叠的修订降级为批注。
- 审查意见书：结论、基本信息、风险清单、法律依据、缺失条款、框架四问。

## 宿主依赖（hostApi 2）

`workbenchLlm`（模型）、`documentExtractor`（PDF 文字）、`electron`（保存对话框）。docx 读写用 `src/main/zip.cjs`（只用 Node zlib）。

## 已知限制

- 没有法规全文库，法条内容不能核对；企业核验（工商信息）未做。
- 合同超过约 24000 字时后文截断送审。
