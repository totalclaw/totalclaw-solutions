# 第三方声明（LC1）

本方案按自身技术栈重写，未复制任何第三方仓库的代码、提示词原文或数据。下表登记参照过功能与交互的项目：

| 项目 | 许可证 | 使用方式 |
|---|---|---|
| [xiaodingfeng/contract-review](https://github.com/xiaodingfeng/contract-review) | MIT | 参照功能：预分析、风险分级、修改建议、模板版本、两版对比、反驳推演 |
| [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)（legal） | Apache-2.0 | 参照 playbook 结构（标准立场 / 可接受范围 / 升级情形）与必争 / 可让 |
| [evolsb/claude-legal-skill](https://github.com/evolsb/claude-legal-skill) | MIT | 参照立场区分与缺失条款补充的思路 |
| [CSlawyer1985/contract-review-pro](https://github.com/CSlawyer1985/contract-review-pro) | 无许可证 | 只借思路（立场声明、框架四问、修订动作分类），未复制任何内容 |
| [CUAD](https://www.atticusprojectai.org/cuad)（The Atticus Project） | CC BY 4.0 | `resources/clause-types.json` 使用其 41 个条款类别名称（未使用数据集与描述文本）。署名：CUAD v1, The Atticus Project |

审查模板（`resources/playbooks/`）与法规清单（`resources/statutes.json`）为本项目自行编写。
