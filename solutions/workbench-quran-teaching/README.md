# 人工智能《古兰经》智能教学平台（演示）

- id：`workbench-quran-teaching`
- 分类：教育
- 类型：workbench
- 入口路由：`/workbenches/quran-teaching`
- 依赖：`workbench-edu-hub`、`workbench-service-settlement`

固定语料导入与校验、章节结构解析、提纲与课程生成、理解图、动态出题、5 名学生个人与群体薄弱点分析、强化教学与复测、图片卡片与视频脚本，中英阿三语。

围绕一条完整教学闭环：标准经文语料包（10 章 265 节，逐文件校验、原文冻结）进入平台后，AI 拆分章/节/词汇/概念/教学单元，按学生水平与课时生成提纲、课程安排与单课计划，形成可点击的理解图；基于锁定经文与批准资料动态生成不同版本的练习与考试（每题可追溯来源）；5 名演示学生产生不同结果，自动识别个人薄弱点与群体共同问题，改一个答案即重算；针对薄弱点生成强化教学、练习与复测并展示前后变化；知识卡片、章节结构图、视频脚本分镜与成片样例；教师端 / 学生端 / 管理层三入口，阿拉伯语 RTL。

## 安装

```bash
npm run tcsol -- install workbench-quran-teaching
```

qiye-app 中按 id `workbench-quran-teaching` 或名称「人工智能《古兰经》智能教学平台（演示）」安装；已安装后随方案仓库发布自动升级，用户数据（`quran-teaching/`）不受影响。
