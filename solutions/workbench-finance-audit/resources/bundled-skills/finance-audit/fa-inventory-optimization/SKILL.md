# 存货优化（fa-inventory-optimization）

按年耗用金额做 ABC 分类，识别呆滞与过时存货，测算可释放的资金占用，给出分类管理与处置建议。自建技能（finance-skills README 声明的 working-capital「库存优化」能力）。

## 加载上下文

- 基准日以项目期间末为准；阈值读 `fa-working-capital-master/reference/判断框架.md`。

## Examples

→ 示例：用户说「哪些物料在压我们的钱」，调用本技能，按库存金额与无动静天数排出呆滞与过时清单。

→ 示例：用户说「帮我们做一次 ABC 分类，定一下盘点频率」，调用本技能，按年耗用金额分 A / B / C 并给出管理建议。

## 第一步：收集数据

```
□ 物料编码、名称
□ 库存金额（账面）
□ 年耗用金额（过去 12 个月出库金额；没有时用库存金额代替并注明）
□ 最后出入库日期
```

## 第二步：ABC 分类

1. 按年耗用金额从大到小排序，计算累计占比。
2. 某物料之前的累计占比 < 80% → A 类；< 95% → B 类；其余 C 类（跨过 80% 的那一项仍算 A）。
3. 管理建议：A 类精细补货、每周盘点；B 类每月盘点；C 类简化管理、按季盘点。

## 第三步：呆滞与过时

```
无动静天数 = 基准日 − 最后出入库日期
> 180 天：呆滞
> 365 天：过时（评估跌价准备与处置）
没有最后出入库日期：不判呆滞，并在说明里列出
可释放资金占用 = 呆滞金额 + 过时金额
```

## 输出模板

```
存货优化分析（基准日 [YYYY-MM-DD]，草稿）
A 类 [n] 项 / [金额]；B 类 [n] 项 / [金额]；C 类 [n] 项 / [金额]
呆滞 [金额]、过时 [金额]，可释放资金占用 [金额]
处置建议：促销 / 调拨 / 退货 / 报废（报废与跌价准备须审批）
```

## 置信度评估

- 高：有年耗用金额与最后出入库日期。
- 中：年耗用金额用库存金额代替。
- 低：缺最后出入库日期的物料超过三成。

## 升级条件

- 过时存货超过存货总额 5% → 评估跌价准备，报财务经理。
- 拟报废或大额折价处置 → 按审批权限报批，本技能只出建议。
