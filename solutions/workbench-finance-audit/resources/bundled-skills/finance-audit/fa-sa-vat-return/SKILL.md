# 沙特增值税申报底稿（fa-sa-vat-return）

给沙特（ZATCA）增值税申报准备底稿：把一个税期的销项、进项按申报表各栏归类，算出应缴或留抵，列出需要人工确认的事项。**只出底稿，申报由人登录 ZATCA 平台提交。**

> 在财会审计工作台里，这些数由 C1「沙特：增值税申报底稿」模式的规则引擎算出，模型不重算；本技能给对话 / 任务中心里的智能体解释口径用。所有沙特口径在当地专业人员审核前都是「草稿口径，需当地专业人士复核」。

## 税率与期限从哪里取

- 标准税率：地区规则 `sa.vat_standard_rate`（2020-07-01 起为 15%）。
- 申报频率：`sa.vat_filing_frequency`（上年应税销售额超过 4000 万里亚尔按月，其余按季）。
- 申报与缴纳期限：`sa.vat_return_due`（申报期结束后下一个月的最后一天）。
- 上期差错可在本期并入的上限：`sa.vat_correction_threshold`（净差错不超过 5,000 里亚尔）；超过的不得并入，按规定另行申报更正。
- 以上数值以规则表里当期生效的版本为准；规则表与本说明不一致时，以规则表为准，并提醒用户核对最新规定。

## 各栏怎么归

| 栏 | 内容 | 税额 |
|---|---|---|
| 1 | 标准税率销售 | 发票上的增值税额 |
| 3 | 国内零税率销售 | 0 |
| 4 | 出口 | 0 |
| 5 | 免税销售 | 0 |
| 7 | 国内标准税率采购 | 可抵扣的进项税额（标为不可抵扣的不计） |
| 8 | 进口（海关已缴增值税） | 海关缴款凭证上的增值税 |
| 9 | 进口（反向征收） | 按标准税率自行计算，同额计入销项 |
| 10 / 11 | 零税率采购 / 免税采购 | 0 |

- 本期应纳 = 销项合计（第 1 栏 + 反向征收自行计算的销项）− 可抵扣进项合计（第 7、8、9 栏）。
- 应缴 = 本期应纳 + 上期更正（未超上限）− 上期留抵；为负时是期末留抵或可申请退税。
- 不征税的行、作废发票、不在本税期的行不进申报表，单独列出。

## 必须核对的事项

1. 每行税额与「不含税金额 × 标准税率」的差异，超过容差的逐张核对发票。
2. 类别没写、税额又是 0 的行：零税率、免税还是不征税必须写明，否则不能出底稿。
3. 标准税务发票（B2B）是否有买方增值税号（见 `fa-sa-einvoice`）。
4. 进项是否用于免税项目或不可抵扣用途（如员工娱乐），这部分不得抵扣。
5. 反向征收、进口的凭证是否齐全。

## 升级条件

- 上期差错超过 `sa.vat_correction_threshold`：停止并提醒按规定另行申报更正。
- 进项发票状态异常、或与销售方申报不一致：列为高风险，不抵扣。
- 应缴金额与上期相比变化明显且说不清原因：交复核人确认。
