# 应付账款策略（fa-payables-strategy）

按供应商汇总未清应付、占比、平均账期与近期到期金额，识别集中度高、账期偏短的供应商，给出谈判与付款节奏建议。自建技能（finance-skills README 声明的 working-capital「应付账款策略」能力）。

## 加载上下文

- 基准日以项目期间末为准；阈值读 `fa-working-capital-master/reference/判断框架.md`。
- 付款排程转现金管理模块（只出付款计划草稿，不付款）。

## Examples

→ 示例：用户说「哪些供应商可以去谈更长的账期」，调用本技能，列出账期短于平均、金额较大的供应商。

→ 示例：用户说「下个月要付的货款太集中了」，调用本技能，统计 30 天内到期金额并交现金管理排计划。

## 第一步：收集数据

```
□ 供应商、单据号、单据日期、到期日、未清金额（应付明细）
□ 本期营业成本与期间天数（算 DPO）
```

## 第二步：分析

```
供应商未清金额与占比：占比 ≥ 30% → 关注（断供与议价风险）
平均账期 = 平均（到期日 − 单据日期）
30 天内到期金额：到期日在基准日后 30 天内
DPO = 应付 / 成本 × 天数
```

## 第三步：策略建议

- 账期明显短于同类供应商且金额较大的：列入谈判清单，谈判理由要基于合作年限、采购量、付款记录。
- 集中度高的：评估备选供应商，避免单一依赖。
- 付款节奏：30 天内到期的与资金计划对表，资金紧张时由现金管理模块按优先级排计划。
- 不以拖欠代替谈判；不改合同付款条件，条件变更由采购与法务按流程完成。

## 输出模板

```
应付策略（基准日 [YYYY-MM-DD]，草稿）
供应商前十：[名称 / 未清 / 占比 / 平均账期 / 30 天内到期]
谈判清单：[供应商 / 现账期 / 建议目标账期 / 理由]
```

## 置信度评估

- 高：应付明细带单据日期与到期日。
- 中：缺单据日期，账期无法计算。
- 低：只有余额没有明细。

## 升级条件

- 单一供应商应付占比 ≥ 30% → 报 CFO。
- 有逾期应付且供应商已催款 → 转现金管理模块按 P1 处理并报财务经理。

1. 按调用方给的 `output_language`（zh-CN / en-US / ar）写全部说明文字。
