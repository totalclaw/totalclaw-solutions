# 判断框架 — 营运资本优化（自建）

> finance-skills README 声明了 working-capital 场景但仓库没有文件；本框架为财会审计解决方案自建，量化默认值与工作台 `thresholds/working-capital.json` 一致，可在公司档案里按企业政策调整。

## 核心原则

营运资本管理的目标是「用更少的钱把生意做下来」：应收收得快、存货压得少、应付付得稳。三段一起看，不能只压其中一段——把应付拖到供应商断供、把存货压到缺货，都是更大的损失。

## 指标口径

| 指标 | 公式 | 说明 |
|---|---|---|
| DSO 应收周转天数 | 期末应收余额 / 期间营业收入 × 期间天数 | 应收用未清金额；收入与期间天数同口径（月度用当月天数，年度用 365） |
| DIO 存货周转天数 | 期末存货余额 / 期间营业成本 × 期间天数 | 存货用账面金额 |
| DPO 应付周转天数 | 期末应付余额 / 期间营业成本 × 期间天数 | 应付用未清金额 |
| CCC 现金转换周期 | DSO + DIO − DPO | 天数越短，被占用的现金越少 |
| 每改善 1 天释放的现金 | 应收：收入 / 天数；存货、应付：成本 / 天数 | 用来把天数换成金额 |

## 异常类型与处理方式

### 类型一：应收周转变慢（DSO 上升）

- 先看逾期应收：逾期金额占应收 30% 以上，按客户排出前十，交应收与账龄模块做催收与信用评估。
- 再看结构：大客户账期是否被放宽、是否有集中到期未回款。
- 处理：收紧新单信用、对逾期客户分阶段催收；需要融资的看应收保理。

### 类型二：存货积压（DIO 上升）

- ABC 分类：按年耗用金额排序，累计占比 80% 以内为 A 类、80%–95% 为 B 类、其余为 C 类（跨过 80% 的那一项仍算 A）。
- 呆滞与过时：超过 180 天无出入库为呆滞，超过 365 天为过时。
- 处理：A 类精细补货、B 类定期盘点、C 类简化管理；呆滞品促销或调拨，过时品评估跌价准备与处置。

### 类型三：应付策略

- 供应商集中度：单一供应商应付占比 ≥ 30% 为关注，评估断供风险与议价能力。
- 账期：账期明显短于同类供应商的，列入谈判清单；不得以拖欠代替谈判。
- 30 天内到期金额与资金计划对表，资金紧张时转现金管理模块排付款计划（只出计划，不付款）。

### 类型四：供应链金融

| 方案 | 现金效应 | 成本承担 | 默认测算参数 |
|---|---|---|---|
| 反向保理（供应商融资） | 付款期延长 N 天，保留现金 = 日均成本 × N | 通常由供应商承担贴现，企业需授信 | N = 30 天，年化 4% |
| 应收保理 | 提前收回应收 × 预付比例 | 企业承担融资成本 | 预付 80%，年化 4% |
| 动态折扣 | 提前付出现金，换取折扣 | 折扣即节约 | 折扣 1% |
| 存货融资 | 存货 × 折扣率 | 企业承担融资成本 | 折扣率 50%，年化 4% |

测算只用于比较方案，利率与费率以金融机构正式报价为准；引入任何方案都须 CFO 决策。

## 置信度评估

| 置信度 | 条件 |
|---|---|
| 高 | 收入、成本、应收、应付、存货口径一致且有明细 |
| 中 | 只有余额没有明细，或期间天数口径需确认 |
| 低 | 收入或成本缺失，或明细与余额相差较大 |

## 升级触发条件

- 现金转换周期比上期延长 15 天以上
- 逾期应收占应收 30% 以上
- 过时存货超过存货总额 5%
- 单一供应商应付占比 ≥ 30%
- 拟引入任何供应链金融方案
