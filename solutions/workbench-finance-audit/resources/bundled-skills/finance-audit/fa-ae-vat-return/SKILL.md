# 阿联酋增值税申报底稿（VAT 201）（fa-ae-vat-return）

给阿联酋（FTA）增值税申报准备 VAT 201 底稿。**只出底稿，申报由人登录 FTA 平台提交。** 结果在当地专业人员审核前一律是「草稿口径，需当地专业人士复核」。

> 在财会审计工作台里，这些数由 C1「阿联酋：增值税申报底稿（VAT 201）」模式的规则引擎算出；本技能给对话里的智能体解释口径用。

## 税率与期限

- 标准税率：地区规则 `ae.vat_standard_rate`（5%）。
- 申报与缴纳期限：`ae.vat_return_due`（税期结束后第 28 天）。
- 差错更正：差错导致的税额差异超过 `ae.vat_correction_threshold`（10,000 迪拉姆）的，须提交自愿披露；未超过的可在下一期申报中调整。
- 以上以规则表当期生效的版本为准。

## 各栏怎么归

| 栏 | 内容 |
|---|---|
| 1a–1g | 标准税率供应，按酋长国（阿布扎比、迪拜、沙迦、阿治曼、乌姆盖万、哈伊马角、富查伊拉）分列 |
| 2 | 给游客退税（适用时） |
| 3 | 适用反向征收的供应（如从境外购进的服务），按 5% 自行计算销项 |
| 4 | 零税率供应（含出口） |
| 5 | 免税供应 |
| 6 | 进口货物（登记纳税人按反向征收申报） |
| 9 | 标准税率费用：可抵扣的进项 |
| 10 | 适用反向征收的供应：可抵扣部分 |
| 12 / 13 / 14 | 应缴税额合计 / 可抵扣税额合计 / 本期应缴 |

- 反向征收与进口货物两边同额（第 3、6 栏计销项，第 10 栏抵扣），可全额抵扣时对应缴额没有影响，但必须申报。
- 发票必备字段见 `ae.tax_invoice_required_fields`；没有合规税务发票的进项不得抵扣。

## 必须核对的事项

1. 标准税率行没有酋长国信息的，第 1 栏无法分列，要补。
2. 每行税额与「不含税金额 × 5%」的差异。
3. 零税率与免税要分清：零税率可抵扣进项，免税对应的进项须分摊不得抵扣。
4. 娱乐、员工个人用途等受限进项不得抵扣。

## 升级条件

- 差错超过自愿披露门槛：停止，交批准人。
- 进项发票不合规或缺失：不抵扣，列入风险清单。
