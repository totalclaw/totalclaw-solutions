# 供应链金融（fa-supply-chain-finance）

比较反向保理、应收保理、动态折扣、存货融资四类供应链金融方案的现金效应与年化成本，供管理层选择。自建技能（finance-skills README 声明的 working-capital「供应链金融」能力）。

## 加载上下文

- 测算参数（延长天数、预付比例、融资利率、折扣比例）读 `fa-working-capital-master/reference/判断框架.md`，都是默认假设，以金融机构正式报价为准。

## Examples

→ 示例：用户说「资金有点紧，有没有不加贷款的办法」，调用本技能，测算反向保理与应收保理能释放多少现金。

→ 示例：用户说「供应商愿意给 1% 折扣换提前付款，划算吗」，调用本技能，测算动态折扣的节约与现金占用。

## 第一步：收集数据

```
□ 应收未清金额（应收保理）
□ 应付未清金额与 30 天内到期金额（反向保理、动态折扣）
□ 存货金额（存货融资）
□ 营业成本与期间天数（日均成本）
```

## 第二步：测算

| 方案 | 现金效应 | 年化成本 |
|---|---|---|
| 反向保理 | 日均成本 × 延长天数（默认 30 天） | 现金效应 × 融资利率（默认 4%） |
| 应收保理 | 应收 × 预付比例（默认 80%） | 现金效应 × 融资利率 |
| 动态折扣 | −30 天内到期的应付（提前付出） | −应付 × 折扣比例（默认 1%，负数为节约） |
| 存货融资 | 存货 × 折扣率（默认 50%） | 现金效应 × 融资利率 |

## 第三步：比较与建议

- 按「释放 1 元现金的成本」排序；动态折扣只在现金充裕时考虑。
- 反向保理需要企业授信与供应商配合，评估对供应商关系的影响。
- 应收保理注意有无追索权、对客户关系与报表列报（终止确认）的影响，需会计口径确认。

## 置信度评估

- 高：有正式报价。
- 中：用默认参数测算。
- 低：基数数据缺失。

## 升级条件

- 拟引入任何供应链金融方案 → CFO 决策；涉及担保、追索权或报表终止确认 → 报财务经理与审计确认。

## 边界

- 只出测算与比较；不与金融机构签约、不改供应商付款条件、不对外发送。
