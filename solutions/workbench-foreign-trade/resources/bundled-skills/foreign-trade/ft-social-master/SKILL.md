# 外贸技能目录 · 网站与社媒

外贸技能库里归在「网站与社媒」的技能共 18 个。先按下表挑最贴近任务的一个，读它的 SKILL.md 再做；
几个都相关时先读描述最具体的那个。通用做法（工具替换、发信要人确认、数据落到工作区文件）见 `ft-conventions`。

| 技能 | 用途 |
|---|---|
| `ft-api-monitoring` | 电商接口与 Webhook 监控方案：健康检查、告警规则、SLA 报告模板与集成校验（仅能力提纲）。 |
| `ft-b2b-website-builder` | 外贸 B2B 静态独立站：按采购搜索意图规划页面，构建期预生成每页完整 HTML，Cloudflare Pages + D1 先入库再邮件通知的可靠询盘，质量闸门通过才部署。 |
| `ft-brand-monitoring` | 品牌舆情监控：在 Reddit、新闻、YouTube 等渠道追踪品牌提及，做情感、趋势与危机预警（附脚本）。 |
| `ft-domain-monitoring` | 网站域名与 SSL 证书监控方案：到期提醒、DNS 异常检测与安全评级（仅能力提纲）。 |
| `ft-ecommerce-social-media-marketing` | 电商社媒营销：分平台策略、内容日历、社交电商、达人合作与社群运营。 |
| `ft-etsy-social-media-marketing` | Etsy 社媒引流：Pinterest、Instagram、TikTok 推广策略（仅能力提纲）。 |
| `ft-file-integrity-monitoring` | 电商网站文件完整性监控方案：文件变更检测、篡改告警、安全基线与恢复流程（仅能力提纲）。 |
| `ft-influencer-outreach` | 电商达人合作：按平台与受众找达人、外联模板、报价谈判、合同与效果追踪（仅能力提纲）。 |
| `ft-kol-imitation` | 社媒意见领袖风格模仿：分析行业领英 / 社媒意见领袖的内容结构与风格，应用到自家品牌账号。 |
| `ft-linkedin-marketing` | 领英营销与客户开发：个人主页优化、内容策略、客户开发六步流程，按免费 / 付费会员能力分级，在内置浏览器由用户登录后操作。 |
| `ft-localization-testing` | 电商网站本地化测试方案：多语言 QA、货币校验、物流信息核对与区域合规检查（仅能力提纲）。 |
| `ft-public-status-page` | 电商公开状态页设计：状态页架构、故障通告模板、订阅通知与可用性报告（仅能力提纲）。 |
| `ft-reddit-engagement` | Reddit 外贸社区互动：挑选相关版块，用专业评论建立信任、引导 B2B 客户，避免硬广与违规。 |
| `ft-seo-aeo` | SEO 与 AI 搜索优化文章：面向搜索引擎与 AI 问答引擎的外贸 B2B 文章选题、结构与关键词布局。 |
| `ft-social-media` | 海外社媒内容策略与日历：Facebook、Instagram、TikTok、YouTube 的内容规划、发布日历与互动策略。 |
| `ft-social-media-monitor` | 电商社媒监听：在 Reddit、TikTok、Instagram、X、YouTube 设关键词与话题监听，追踪情感、竞品与危机（仅能力提纲）。 |
| `ft-synthetic-monitoring` | 电商网站拨测方案：自动模拟加购、结账、支付流程，设告警规则与性能基线（仅能力提纲）。 |
| `ft-visual-regression-testing` | 电商网站视觉回归测试方案：截图比对流程、移动/桌面视觉检查与变更告警（仅能力提纲）。 |
