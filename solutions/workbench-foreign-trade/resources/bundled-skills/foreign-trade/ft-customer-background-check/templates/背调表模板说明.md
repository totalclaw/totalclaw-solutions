# 客户背调表模板

## 表格字段说明

### 原始信息字段（客户提供）

| 字段名 | 说明 | 示例 |
|-------|------|------|
| 创建日期 | 客户录入日期 | 4.01 |
| 客户来源 | 获客渠道 | Facebook/Instagram/展会 |
| 身份类型 | 客户业务类型 | 电商卖家/美容院/批发商 |
| 兴趣产品 | 客户感兴趣的产品 | 化妆刷、美妆蛋 |
| 邮箱 | 客户邮箱地址 | xxx@company.com |
| 客户名称 | 客户姓名 | John Smith |
| 客户手机 | 客户联系电话 | p:+447123456789 |
| 地区 | 客户所在国家/地区 | 英国 |
| 公司名称 | 客户声称的公司名 | ABC Trading Ltd |

---

### 背调验证字段

| 字段名 | 说明 | 填写内容 |
|-------|------|---------|
| **匹配依据** | 判断客户与公司关联的证据 | 详细说明匹配或不匹配的原因 |
| **公司注册号** | 官方注册号 | 如：13291250 |
| **公司状态** | Active/Dissolved等 | Active |
| **邮箱验证** | 邮箱有效性验证结果 | ✅ 企业邮箱有效 / ⚠️ 个人邮箱 |
| **电话验证** | 电话格式验证结果 | ✅ 英国手机号格式有效 |
| **背调状态** | 综合风险等级 | ✅ 可信 / ⚠️ 需补充 / ❌ 高风险 |
| **验证建议** | 后续行动建议 | 具体验证或跟进建议 |

## Excel表格模板

可使用以下Python代码生成模板：

```python
import pandas as pd

columns = [
    # 原始信息
    '创建日期', '客户来源', 'ad name', '身份类型', '兴趣产品',
    '邮箱', '客户名称', '客户手机', '地区', '公司名称',
    '分配跟进人', '客户价值', '潜力分析', '跟进建议',

    # 公司名称获取（新增）
    '公司名称来源', '推断置信度',

    # 客户身份推断（新增）
    '推断身份类型', '推断依据', '身份置信度',

    # 背调验证
    '匹配依据', '公司注册号', '公司状态',
    '邮箱验证', '电话验证', '背调状态', '验证建议',

    # 社交媒体验证（新增）
    'LinkedIn', 'Facebook', 'Instagram', 'YouTube',

    # 电商平台验证（新增）
    'Amazon店铺', 'eBay店铺', 'Alibaba', 'Etsy店铺',

    # 海关贸易验证（新增）
    '进口记录', '最近进口日期', '进口品类', '主要供应商', '年进口量',

    # 兴趣产品匹配（新增）
    '产品与身份匹配', '采购量合理性', '产品敏感度',

    # 参考信息
    '搜索到的参考信息(仅供参考)'
]

df = pd.DataFrame(columns=columns)
df.to_excel('客户背调表_模板_v1.1.xlsx', index=False)
```

## 背调状态标注规范

| 状态 | 符号 | 含义 |
|------|------|------|
| 可信 | ✅ | 有直接匹配依据，低风险 |
| 需补充 | ⚠️ | 部分信息缺失，需客户补充材料 |
| 高风险 | ❌ | 无匹配依据或存在矛盾，需警惕 |
| 无法核实 | ⚠️ | 信息不足，无法确认真实性 |
