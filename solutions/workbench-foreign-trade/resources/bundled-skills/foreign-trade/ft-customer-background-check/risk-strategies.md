# 风控策略 (Risk Control Strategies)

本文档根据客户背调结果，提供具体的风控建议，包括付款方式、发货策略和合同条款。

---

## 一、风险等级与应对策略概览

| 风险等级 | 分数范围 | 标识 | 总体策略 |
|----------|----------|------|----------|
| 低风险 | 80-100 | ✅ | 正常合作流程 |
| 中风险 | 50-79 | ⚠️ | 谨慎合作，加强风控 |
| 无法核实 | 20-49 | ⚠️ | 限制合作，严格风控 |
| 高风险 | 0-19 | ❌ | 不建议合作或极严格条件 |

---

## 二、低风险客户 (80-100分) ✅

### 评估特征

- 公司成立时间长（>3年），状态正常运营
- 客户为公司董事/股东，且有完整验证
- 企业邮箱、电话与公司信息匹配
- 有海关进口记录或完整数字资产
- 采购量与公司规模匹配

### 付款方式建议

| 方式 | 推荐程度 | 说明 |
|------|----------|------|
| T/T 预付30% | ⭐⭐⭐ 推荐 | 标准30%预付，发货前付清 |
| T/T 预付50% | ⭐⭐ 可选 | 对于大额订单 |
| 信用证 (L/C) | ⭐⭐ 可选 | 适用于大额订单 |
| 赊销 (OA) | ⭐ 可选 | 仅限长期合作且信用良好的客户 |

### 发货策略

- ✅ 正常发货流程
- ✅ 可接受分批发货
- ✅ 标准质量检验流程

### 合同条款

使用标准国际贸易合同，包含：
- 质量标准和验收条款
- 交货时间和方式
- 争议解决机制
- 适用法律和仲裁条款

### 特别建议

对于大额订单（>$50,000）：
- 建议购买出口信用保险
- 定期更新背调信息（每年一次）

---

## 三、中风险客户 (50-79分) ⚠️

### 评估特征

- 公司成立时间较短（1-3年），但状态正常
- 客户身份部分验证（如LinkedIn确认，但无官方董事记录）
- 存在部分信息不一致
- 采购量略高于公司规模预期

### 付款方式建议

| 方式 | 推荐程度 | 说明 |
|------|----------|------|
| T/T 预付50% | ⭐⭐⭐ 推荐 | 提高预付比例 |
| T/T 全额预付 | ⭐⭐ 可选 | 适用于中等金额订单 |
| 信用证 (L/C) | ⭐⭐⭐ 推荐 | 银行担保，降低风险 |
| D/P (付款交单) | ⭐ 可选 | 需谨慎评估 |

### 发货策略

- ✅ 分批发货，每批付款后发货
- ✅ 首次合作建议样品单验证
- ⚠️ 保留货权直到全额付款
- ⚠️ 加强出货前质量检验

### 合同条款

在标准合同基础上增加：

**验收条款**：
```
1. 买方需在收到货物后7个工作日内完成验收
2. 如未在规定时间内提出异议，视为验收合格
3. 验收标准以双方确认的样品为准
```

**所有权保留条款**：
```
货物所有权在买方全额付款前仍属于卖方
如买方未能按时付款，卖方有权收回货物
```

### 特别建议

- 首次订单金额控制在$10,000以内
- 合作3次以上且付款记录良好后，可考虑调整风险等级
- 每6个月更新一次背调信息

---

## 四、无法核实客户 (20-49分) ⚠️

### 评估特征

- 公司信息无法通过官方渠道验证
- 客户与公司关系无法确认
- 使用个人邮箱而非企业邮箱
- 无海关记录，数字资产缺失
- 多个验证维度使用降级方案仍未获得有效信息

### 付款方式建议

| 方式 | 推荐程度 | 说明 |
|------|----------|------|
| T/T 100%预付 | ⭐⭐⭐ 必须要求 | 必须全额预付 |
| 信用证 (L/C) | ⭐⭐⭐ 推荐 | 不可撤销即期信用证 |
| 西联汇款 | ⭐⭐ 可选 | 小额订单快速到账 |
| D/P, D/A | ❌ 不推荐 | 风险过高 |

### 发货策略

- ⚠️ 样品先行：要求客户先付费购买样品
- ⚠️ 款到发货：收到全款后安排生产发货
- ❌ 不接受赊销或分期付款
- ⚠️ 货物追踪：全程跟踪物流状态

### 合同条款

**仲裁条款**：
```
所有争议应提交[中国国际经济贸易仲裁委员会]
仲裁地点：[中国深圳]
仲裁语言：中文
仲裁裁决是终局的，对双方均有约束力
```

**适用法律条款**：
```
本合同适用中华人民共和国法律
```

**质量争议处理**：
```
如发生质量争议：
1. 买方需在收到货物后3个工作日内书面通知卖方
2. 双方共同委托第三方检验机构检验
3. 检验费用由责任方承担
```

### 特别建议

- **强烈建议**要求客户提供：
  - 公司注册证书副本
  - 董事身份证明
  - 最近一年财务报表
  - 银行资信证明

- 如客户拒绝提供以上材料，建议放弃合作

---

## 五、高风险客户 (0-19分) ❌

### 评估特征

- 公司状态异常（已注销/清算中）
- 存在欺诈信号（虚假信息、仿冒公司）
- 高风险国家/地区
- 公司成立极短（<6个月）却下大额订单
- 采购量严重超出公司规模
- 拒绝提供任何验证信息

### 付款方式建议

| 方式 | 推荐程度 | 说明 |
|------|----------|------|
| T/T 100%预付 | ⭐⭐ 唯一选项 | 必须100%预付，款到生产 |
| 信用证 | ⭐⭐ 可考虑 | 不可撤销信用证，需确认开证行资质 |
| 任何赊销方式 | ❌ 禁止 | 绝对不接受赊销 |

### 发货策略

- ❌ 不建议发货，除非满足以下所有条件：
  1. 全额款项已到账并确认
  2. 银行确认无退单风险
  3. 客户提供了额外的担保或保证金

- ⚠️ 如必须合作：
  - 分小批发货
  - 每批全额付款后再发下一批
  - 全程视频记录发货过程

### 合同条款

**特殊保护条款**：

```
1. 预付款条款
   买方需在签订合同后3个工作日内支付100%货款
   如未按时付款，卖方有权取消订单

2. 违约金条款
   如买方取消订单，预付款不予退还
   作为对卖方生产准备的补偿

3. 法律管辖
   合同适用卖方所在地法律
   争议提交卖方所在地法院或仲裁机构

4. 担保条款
   买方需提供银行保函或保证金
```

### 特别建议

**建议放弃合作的情况**：

1. ⛔ 公司已注销或清算
2. ⛔ 存在明显的欺诈信号
3. ⛔ 来自受制裁国家/地区
4. ⛔ 拒绝提供任何身份验证信息
5. ⛔ 要求使用可疑的付款方式

**如坚持合作**：

1. 购买出口信用保险
2. 要求客户提供担保人
3. 单次订单金额控制在$5,000以内
4. 每次合作都重新评估风险

## 六、特殊场景风控策略

### 6.1 大额订单 (> $100,000)

无论风险等级，对于大额订单都应：

1. **付款方式**：
   - 信用证为首选
   - 如T/T，要求分批付款（30%-40%-30%）

2. **保险措施**：
   - 购买出口信用保险
   - 确认买方信用额度

3. **合同要求**：
   - 加入严格的验收标准
   - 明确延迟付款的罚则
   - 加入所有权保留条款

### 6.2 新客户首单

新客户首次订单的特殊要求：

| 金额范围 | 风控措施 |
|----------|----------|
| < $5,000 | 标准流程，可根据背调结果决定 |
| $5,000-$20,000 | 至少50%预付，建议样品验证 |
| $20,000-$50,000 | 至少70%预付，信用证优先 |
| > $50,000 | 100%预付或信用证，强制背调 |

### 6.3 高风险国家/地区

对于特定国家/地区的额外风控：

**需额外谨慎的地区**：
- 受国际制裁的国家
- 外汇管制严格的国家
- 政治局势不稳定的国家

**风控措施**：
- 必须100%预付或信用证
- 确认外汇支付渠道畅通
- 咨询出口信用保险公司

### 6.4 老客户异常行为

对于长期合作客户出现异常行为：

**异常信号**：
- 突然增大订单金额
- 要求延长付款期限
- 频繁更改收货地址
- 联系人突然更换

**应对措施**：
- 重新执行完整背调
- 联系原确认的联系人核实
- 暂停赊销，恢复预付模式

## 七、风控决策流程

```
背调完成 → 获取总分和风险等级
    ↓
风险等级判定:
    ↓
┌─────────────────────────────────────────────────┐
│ ✅ 低风险 (80-100)                               │
│    → 标准合作流程                                │
│    → 推荐30%预付                                 │
├─────────────────────────────────────────────────┤
│ ⚠️ 中风险 (50-79)                               │
│    → 谨慎合作                                    │
│    → 要求50%预付或信用证                         │
│    → 建议样品验证                                │
├─────────────────────────────────────────────────┤
│ ⚠️ 无法核实 (20-49)                             │
│    → 限制合作                                    │
│    → 必须100%预付                                │
│    → 要求客户提供证明文件                         │
├─────────────────────────────────────────────────┤
│ ❌ 高风险 (0-19)                                 │
│    → 建议放弃合作                                │
│    → 如必须合作：100%预付 + 担保                 │
└─────────────────────────────────────────────────┘
    ↓
生成风控建议报告
    ↓
记录决策依据
```
