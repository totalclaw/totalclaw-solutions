# Step 1: 多平台竞品识别与对标

> 目标：在 4 大平台系统性识别 Top 竞争对手，建立竞品数据库（20-30家）。
> 完成后自动执行渠道检测（见 SKILL.md）。

---

## 1.1 搜索关键词准备

在开始扫描之前，先扩展搜索关键词矩阵：

```
输入: 用户提供的产品关键词（如 "tube mill machine"）

扩展为:
├── 核心词: tube mill machine
├── 同义词: pipe making machine, tube forming machine, pipe mill
├── 上位词: steel processing equipment, metal forming machinery
├── 应用词: stainless steel tube mill, carbon steel pipe production line
├── 采购词: tube mill machine manufacturer, tube mill supplier
└── 品牌词: [从搜索结果中提取竞品品牌名]
```

**方法**: web_search `"[产品关键词]" synonyms OR "also known as" OR alternatives`

## 1.2 四平台扫描

### Platform A: Alibaba.com（国际B2B）

**搜索方法**:
```
web_search: "[产品关键词]" site:alibaba.com
web_search: "[同义词]" site:alibaba.com supplier manufacturer
```

**提取数据**（每家企业）:

| 字段 | 提取方式 | 用途 |
|------|---------|------|
| 公司名（英文） | 店铺页 | 唯一标识 |
| 地址/城市 | 店铺页 | 产业集群判断 |
| 经营年限 | 店铺页 "X years" | 稳定性 |
| 交易等级 | 金品/Verified/Trade Assurance | 平台信任度 |
| 员工规模 | 公司介绍页 | 规模估算 |
| 主营产品 | 产品列表 | 专业度判断 |
| 认证 | ISO/CE/SGS | 合规能力 |
| 最近回复率 | 店铺页 | 活跃度 |
| 最低起订量 (MOQ) | 产品页 | 定位判断 |
| 价格区间 | 产品页 | 定价对标 |

**重点关注**:
- 🔍 金品诚企 (Gold Supplier) = 年付费会员，有一定实力
- 🔍 Verified Supplier = 通过 SGS/BV 第三方验厂
- 🔍 Trade Assurance = 有交易保障
- 🔍 经营 10年+ = 稳定玩家
- ⚠️ 仅有基础会员 + 无认证 + 产品杂 = 贸易商/铺货型

**输出**: Top 5 Alibaba 竞品表

---

### Platform B: 1688.com（国内B2B）

**搜索方法**:
```
web_search: "[产品中文关键词]" site:1688.com
web_search: "[产品中文关键词]" 1688 实力商家 工厂
```

> 注意: 1688.com 有 CAPTCHA 防护，web_extract 可能被拦截。优先使用 web_search 搜索结果页获取信息。

**提取数据**:

| 字段 | 提取方式 | 用途 |
|------|---------|------|
| 公司名（中文） | 搜索结果 | 唯一标识 |
| 城市 | 搜索结果 | 产业集群 |
| 实力商家标识 | 搜索结果 | 平台认可度 |
| 价格区间 | 搜索结果 | 国内价格基准（FOB 参考） |
| 交易量/成交额 | 搜索结果 | 规模信号 |
| 工厂 vs 贸易商 | 搜索结果标签 | 供应链定位 |

**重点关注**:
- 🔍 实力商家 = 通过审核的优质供应商
- 🔍 超级工厂 = 产能大、供货稳定
- 🔍 有出口能力标识 = 可能同时在 Alibaba 有店
- ⚠️ 1688 价格 ≈ 国内出厂价，是 FOB 价格的参考基准

**交叉验证**: 在 1688 找到的工厂名 → web_search 在 Alibaba 搜索 → 判断是否同时做内贸+外贸

**输出**: Top 5 国内竞品/供应商表

### Platform C: ThomasNet.com（北美工业）

**搜索方法**:
```
web_search: "[产品关键词]" site:thomasnet.com
web_search: "[产品关键词]" thomasnet supplier manufacturer
```

**提取数据**:

| 字段 | 提取方式 | 用途 |
|------|---------|------|
| 公司名 | 搜索结果/公司页 | 唯一标识 |
| 地址 (州/城市) | 公司页 | 地理位置 |
| 成立年份 | 公司页 | 稳定性 |
| 员工数 | 公司页 | 规模 |
| 年营收 | 公司页（如有） | 市场份额参考 |
| Capabilities | 公司页 | 技术能力 |
| 认证 | ISO/AS/ITAR | 合规能力 |
| 服务区域 | 公司页 | 市场范围 |

**重点关注**:
- 🔍 ThomasNet 上的公司多为北美本土制造商/分销商
- 🔍 这里的定价通常是中国出口价的 3-8 倍
- 🔍 有些是制造商，有些是从中国进口后贴牌分销
- ⚠️ 如果 ThomasNet 搜索结果少（<5），说明北美市场小或以进口为主

**输出**: Top 5 北美竞品/分销商表

- [ ] 网站语言支持（英/西/阿/俄/法...）
- [ ] 有无博客/内容营销
- [ ] Schema 标记（Product/Organization）
- [ ] 页面加载速度（主观评估：快/中/慢）

**输出**: Top 10 Google 排名竞品表

## 1.4 渠道检测（自动执行）

竞品地图完成后，立即执行渠道检测：

```
1. Amazon 检测
   web_search: "[产品关键词]" site:amazon.com
   结果判断:
   - 有结果 + 产品BSR < 50000 → HAS_AMAZON = true
   - 无结果 / BSR > 100000 / 仅配件无整机 → HAS_AMAZON = false

2. DTC 检测
   检查竞品数据库中:
   - 有独立品牌官网+电商功能的企业数量
   - ≥3家 → HAS_DTC = true
   - <3家 → HAS_DTC = false

3. 主渠道判断
   基于各平台竞品密度:
   - Alibaba 竞品最多 → PRIMARY = "Alibaba"
   - Google 独立站多 → PRIMARY = "独立站"
   - Amazon 有活跃卖家 → PRIMARY = "Amazon"
   - ThomasNet 为主 → PRIMARY = "ThomasNet/北美分销"
```

**输出渠道检测结果**:

```
## 渠道检测结果
- Amazon: [✅/❌] — [依据]
- DTC/独立站: [✅/❌] — [依据]
- 主渠道: [名称]
- Step 2-5 加载范围: [纯B2B / B2B+Amazon / B2B+DTC / 全渠道]
```
