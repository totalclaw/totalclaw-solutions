### 市场特征

```

- 印度 — 全球增长最快的大型经济体，Make in India 政策推动

- 印度有较高进口关税（10-25%）
- 价格谈判极其激烈

- 印度本地有一定竞争（如 Electronica Hitech, Godrej）

付款习惯: L/C 或 T/T 50% 预付（印度客户习惯砍价）
主要展会: IMTEX (印度) / ACMEE / Dhaka International Trade Fair
B2B平台: IndiaMART / TradeIndia / Alibaba
社交渠道: WhatsApp（最重要）+ LinkedIn
```

### 市场特征

```
优势:
- 沙特 Vision 2030 → 巨额基建+工业化投资

- 大项目需要本地代理/合资
- 沙特本地化要求 (IKTVA)

- 夏季极端高温，户外设备需要特殊适配

付款习惯: L/C 为主 / 政府项目可能有 180 天账期
主要展会: Big 5 (迪拜) / Saudi Build / Automechanika Dubai
B2B平台: Alibaba + TradeKey + 本地代理
社交渠道: WhatsApp + LinkedIn
```

## 西欧 / 北美 / 大洋洲

### 发达市场特征（共性）

```
优势:
- 最大的终端消费市场
- 付款信用好
- 愿意为品牌/质量付溢价
- 规范化采购流程

挑战:
- 本土竞争极强（德国/日本/美国品牌）
- 高标准认证要求（CE/UL/CSA）
- 品牌忠诚度高，替换成本高
- 需要长期品牌建设

切入策略:
- 不打正面价格战
- 以 OEM/ODM 合作切入
- 找利基/本土品牌覆盖不到的细分
- 用定制化+速度作为差异化
```
