## 2.1 市场规模估算

### 估算方法（B2B工业品）

B2B工业品没有公开的BSR/销量数据，需要用代理指标交叉估算：

```
方法 1: 行业报告法（优先）
web_search: "[产品类型] market size 2025 2026"
web_search: "[产品类型] industry report market forecast"
→ 提取全球市场规模 + CAGR + 区域分布

方法 2: 头部企业锚定法
如果知道头部企业年营收（如用户提供"约10亿"）：
→ 头部企业市占率 ≈ 15-25%（集中市场）或 5-10%（分散市场）
→ 全球市场 ≈ 头部营收 / 市占率

方法 3: 贸易数据估算法
web_search: "[HS编码]" import export statistics
→ 从进出口总额反推全球贸易规模
→ 全球市场 ≈ 贸易总额 × 1.5-2.0（含内需）

方法 4: 从业者密度法
Alibaba上搜索结果数量 × 平均年营收估算
→ 粗略市场规模下限
```

**输出**:

```
## 市场规模估算
全球市场规模: ~$X（估算方法: [使用的方法]）
CAGR: X%
中国市场占比: ~X%
北美市场占比: ~X%
欧洲市场占比: ~X%
新兴市场: ~X%
```

## 2.2 市场份额估算

### 规模档位体系

对 Step 1 识别的每家竞品，按代理指标归入规模档位：

| 档位 | 估算年营收 | 判断信号 | 市占率估算 |
|------|-----------|---------|-----------|
| **T1 头部** | >5亿 | 多平台金品+15年+1000人+多国分支+知名品牌 | 15-25% |
| **T2 中大** | 1-5亿 | 金品+10年+300人+独立站成熟+行业认可 | 5-15% |
| **T3 中型** | 3000万-1亿 | 5年+50-300人+部分认证+有独立站 | 1-5% |
| **T4 小型** | 500-3000万 | 3年+10-50人+基础站+主要靠平台 | 0.2-1% |
| **T5 初创** | <500万 | <3年+<10人+无品牌+纯平台依赖 | <0.2% |

### 代理指标权重

| 指标 | 数据来源 | 权重 | 判断方法 |
|------|---------|------|---------|
| **Alibaba 交易等级** | 店铺页 | 25% | 金品>银品>基础 |
| **员工数** | 公司介绍/LinkedIn | 25% | 人均产值 $10-30万 × 员工数 |
| **经营年限** | 店铺页/工商 | 15% | 10年+=成熟, <3年=新进 |
| **认证体系** | ISO/CE/UL/API | 15% | 认证多=投入大=规模信号 |
| **Google 排名** | 搜索结果 | 10% | 首页=品牌力强 |
| **多平台出现** | 交叉搜索 | 10% | 3+平台=覆盖广=有预算 |

## 2.3 SEO 竞争评估

### 关键词难度分析

对核心关键词矩阵（从 Step 1.1 扩展的关键词）逐一评估：

```
搜索方法:

```

| 关键词 | 月搜索量估算 | Google Top 10 构成 | 内容质量 | 进入难度 |
|--------|------------|-------------------|---------|---------|
| [核心词] | | Alibaba×? 独立站×? 内容站×? | 高/中/低 | 难/中/易 |
| [同义词] | | | | |
| [长尾词] | | | | |
| [采购词] | | | | |

**关键指标**:

| 维度 | 评估方法 | 含义 |
|------|---------|------|
| **Top 10 构成** | 统计Alibaba/独立站/内容站的占位 | Alibaba多=SEO空间大（可用独立站超越） |
| **内容质量** | 浏览Top 10页面内容深度 | 内容薄弱=博客/指南有机会 |
| **域名权重** | 判断竞品域名的成熟度 | 新域名多=进入门槛低 |
| **多语言覆盖** | 检查是否有非英语优化 | 无多语言=长尾语言机会 |

### SEO 机会矩阵

```
            搜索量高
              │
    【黄金词】 │ 【竞争词】
    搜索量高   │ 搜索量高
    难度低     │ 难度高
              │
─────────────┼─────────────
              │
    【长尾词】 │ 【鸡肋词】
    搜索量低   │ 搜索量低
    难度低     │ 难度高
              │
            搜索量低

优先攻克: 黄金词 > 长尾词 > 竞争词 > 忽略鸡肋词
```

## 2.4 竞争定位图

### 2×2 定位矩阵

```
价格定位（低→高）X轴
技术/品质定位（低→高）Y轴

        高品质/技术
            │
  象限II    │   象限I
  高品低价   │   高品高价
  （性价比） │  （品牌溢价）
            │
────────────┼────────────
            │
  象限III   │   象限IV
  低品低价   │   低品高价
  （价格战） │  （定价虚高）
            │
        低品质/技术
```

将 Step 1 识别的竞品标注到矩阵中：

```
## 竞争定位图

### 象限I — 高品高价（品牌溢价区）
[德国/日本/北美头部品牌]
- 公司A: 价格 $XX, 特点: ...
- 公司B: 价格 $XX, 特点: ...

### 象限II — 高品低价（性价比区 ← 中国企业通常的目标位）
[中国头部品牌/出海领先者]
- 公司C: 价格 $XX, 特点: ...

### 象限III — 低品低价（价格战区）
[低端中国工厂/印度工厂]
- 公司D: 价格 $XX, 特点: ...

### 象限IV — 低品高价（定价虚高 ← 被挤出的风险最大）
- 公司E: 价格 $XX, 特点: ...
```
