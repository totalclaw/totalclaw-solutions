## 3.3 差异化策略评估

### 差异化选项矩阵

使用 Hormozi 价值方程评分每个差异化方向：

```
                Dream Outcome × Perceived Likelihood
Value = ─────────────────────────────────────────────
                Time Delay × Effort & Sacrifice
```

| 差异化方向 | Dream Outcome (1-10) | Likelihood (1-10) | Time (1-10, 低=快) | Effort (1-10, 低=易) | 得分 | 推荐 |
|-----------|---------------------|-------------------|-------------------|---------------------|------|------|
| **成本领先** | | | | | | |
| **技术差异化** | | | | | | |
| **服务差异化** | | | | | | |
| **定制化能力** | | | | | | |
| **交期速度** | | | | | | |
| **认证优势** | | | | | | |
| **整体方案** | | | | | | |

> 得分 = (Dream × Likelihood) / (Time × Effort)
> 得分 > 2.0 = 强推荐 | 1.0-2.0 = 可行 | < 1.0 = 不推荐

### B2B 制造业常见差异化路径

```
路径1: 成本领先（中国优势）
  → 适用: 标准化产品、价格敏感市场
  → 风险: 内卷、利润薄、难建品牌
  → 倍率: 3-5x（生存级）

路径2: 技术差异化
  → 适用: 有自主研发的企业
  → 如何: 专利、独特工艺、更高精度/效率
  → 倍率: 6-10x（舒适到安全）

路径3: 服务差异化
  → 适用: 需要安装/调试/培训的设备
  → 如何: 海外服务团队、远程支持、快速响应
  → 倍率: 5-8x

路径4: 定制化能力
  → 适用: 非标产品、特殊应用
  → 如何: 快速打样、小批量接受、工程师直接对接
  → 倍率: 6-10x

路径5: 整体解决方案
  → 适用: 产品线宽的企业
  → 如何: 从单机→产线→交钥匙工程
  → 倍率: 8-15x

路径6: 渠道创新
  → 适用: 传统渠道被头部垄断
  → 如何: DTC模式、线上直销、跨境电商
  → 倍率: 因渠道而异
```

## 3.4 阶段性销售目标分解

### Phase 0: 基础建设（0-3个月）| 目标: 0 → 首单

```
目标:
- 完成出海基础设施搭建
- 获取首批询盘并成交1-3单

行动:
□ Alibaba 国际站开通 + 产品上架（20+产品页）
□ 独立站搭建（WordPress + 基础SEO）
□ Google My Business 注册
□ 品牌视觉统一（Logo/VI/产品手册英文版）
□ 3-5个核心关键词的Google Ads 测试
□ 参加1个线上展会或行业论坛

关键指标:
- 月询盘数: 10-30条
- 询盘转化率: 3-5%
- 首单客单价: $X
- 月投入预算: ¥2-5万

瓶颈检查 (Harnish):
- People: 至少1人专职外贸
- Strategy: 核心差异化确定
- Execution: 报价流程 < 24小时
- Cash: 3-6个月运营资金
```

### Phase 1: 验证期（3-6个月）| 目标: 0 → ¥100万

```
目标:
- 验证产品-市场匹配（PMF）
- 建立3-5个付费客户
- 确认可持续的获客渠道

行动:
□ Alibaba P4P广告优化（转化率 > 5%）
□ 独立站内容建设（10+博客文章，SEO长尾词覆盖）
□ 建立客户案例（3个成功案例+视频见证）
□ 开发1-2个区域代理/合作伙伴
□ LinkedIn B2B 内容营销启动
□ 参加1个线下展会（Canton Fair / 行业展）

关键指标:
- 月询盘数: 30-80条
- 询盘转化率: 5-8%
- 月销售额: ¥8-15万
- 复购率: > 20%
- 月投入预算: ¥3-8万

关键验证:
✅ 客户愿意复购 → PMF 成立
✅ 获客成本 < 客单价 × 10% → 单位经济学成立
✅ 有1个渠道能稳定出单 → 渠道验证通过
```

### Phase 2: 增长期（6-12个月）| 目标: ¥100万 → ¥500万

```
目标:
- 规模化验证过的渠道
- 建立品牌影响力
- 拓展2-3个目标区域

行动:
□ Alibaba+Made-in-China 双平台运营
□ Google SEO 核心词进入 Top 20
□ Google Ads 预算提升至 $2-5K/月
□ 建立海外仓/快速交付能力
□ 开发5-10个区域代理商
□ 品牌内容矩阵（YouTube产品视频/WhatsApp社群）
□ CRM系统上线（HubSpot/Zoho）

关键指标:
- 月询盘数: 100-300条
- 月销售额: ¥40-80万
- 客户数: 20-50家
- 区域覆盖: 3-5个国家
- 团队: 3-5人外贸团队
- 月投入预算: ¥8-15万
```

### Phase 3: 规模化（12-24个月）| 目标: ¥500万 → ¥1000万

```
目标:
- 建立可预测的销售引擎
- 品牌在目标市场有认知度
- 组织能力匹配增长速度

行动:
□ 多渠道矩阵稳定运营（Alibaba+独立站+代理）
□ Google SEO 核心词进入 Top 10
□ 参加2-3个国际行业展会
□ 建立区域销售代表/办事处
□ 产品线扩展（基于客户反馈）
□ 品牌故事+企业IP+行业KOL合作
□ 考虑ThomasNet/本土平台入驻

关键指标:
- 月销售额: ¥80-120万
- 客户数: 50-100家
- 复购客户占比: > 40%
- 区域覆盖: 5-10个国家
- 品牌搜索量: 有机增长
- 团队: 8-15人
- 月投入预算: ¥15-30万
```

## 3.5 定价策略（复用 osint-pricing-anatomy）

> 如需深度定价分析，参考 `ft-b2b-osint-research` 技能的 `references/skills/osint-pricing-anatomy.md`

### B2B 工业品定价框架

```
定价公式:
出口价 = 制造成本 × 倍率 × 区域调整系数

倍率诊断（中国制造成本为基准）:
  3x = 💀 危险（仅有微利，任何波动即亏损）
  5x = 😐 生存（能运营但不舒服）
  8x = 😊 舒适（有营销预算+售后能力）
  10x+ = 🏰 安全（品牌溢价+渠道利润空间）
```

### 定价策略选择

| 策略 | 适用场景 | 倍率区间 | 风险 |
|------|---------|---------|------|
| **渗透定价** | 新市场、抢份额 | 3-5x | 利润薄、品牌低端化 |
| **价值定价** | 有差异化、有故事 | 5-8x | 需要营销支撑 |
| **品牌溢价** | 技术领先、有认证 | 8-12x | 需要长期品牌投入 |
| **分层定价** | 产品线宽 | 混合 | 管理复杂度高 |

### 渠道价格体系

```
FOB 出厂价: $X（制造成本 × 1.3-1.5）
↓
Alibaba 报价: $X（FOB × 1.1-1.3，含平台费+利润）
↓
独立站价格: $X（FOB × 1.5-2.0，含运营+品牌溢价）
↓
代理商价格: $X（终端零售 × 0.6-0.7，给代理利润空间）
↓
终端用户价格: $X（参考北美/欧洲本土品牌的 60-80%）
```
