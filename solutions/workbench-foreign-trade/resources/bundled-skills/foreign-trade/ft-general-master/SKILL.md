# 外贸技能目录 · 方法与工作方式

外贸技能库里归在「方法与工作方式」的技能共 11 个。先按下表挑最贴近任务的一个，读它的 SKILL.md 再做；
几个都相关时先读描述最具体的那个。通用做法（工具替换、发信要人确认、数据落到工作区文件）见 `ft-conventions`。

| 技能 | 用途 |
|---|---|
| `ft-chat-memory` | 历史对话查询：用户问到之前、上次谈过的内容时，按时间窗口与关键词检索历史会话并引用原话。 |
| `ft-data-directory` | 外贸资料目录管理：按公司 / 客户 / 资料库结构初始化知识档案并持续维护，后续技能按文件和行号引用。 |
| `ft-onboarding` | 新公司营销资料包：公司介绍、产品定位、目标客户画像与营销策略一套方案，写进工作区档案供后续技能使用。 |
| `ft-sales-playbook` | 销冠经验封装：把资深业务员的隐性经验整理成新人可复用的标准作业流程、话术库与知识体系。 |
| `ft-six-thinking-hats` | 六顶思考帽决策教练：用六顶思考帽方法辅助接单、定价、换供应商等复杂外贸决策，输出各视角要点与结论。 |
| `ft-skill-distill` | 按关键词→语义(阈值0.75)→读目录三段选技能；会话后回顾对话，更新画像与记忆，提炼技能草案，用户确认后才保存。 |
| `ft-skill-generator` | 外贸技能生成器：按用户描述的业务场景生成符合本产品技能格式的新外贸技能草稿，用户确认后再保存。 |
| `ft-strategic-growth-advisor` | 增长战略顾问：用 Rumelt 诊断、波特五力、Helmer 七种力量、Hormozi 价值方程等框架诊断瓶颈，给增长路径与行动计划。 |
| `ft-trade-knowledge-base` | 外贸业务知识库：公司档案、客户档案、资料库的 Markdown 模板与批量导入规则，回答问题和写信前先读档案。 |
| `ft-trade-onboarding-memory` | 首次了解用户的出口产品、目标市场和客户类型，按用户原话写入公司档案与决策记录，新会话先读已有资料不重复询问。 |
| `ft-trade-team-roles` | 外贸团队六角色（协调/销售/供应链/运营/财务/培训）分工与协作：共享五个工作文件、状态块格式、异常即停；报价与毛利交规则计算。 |
