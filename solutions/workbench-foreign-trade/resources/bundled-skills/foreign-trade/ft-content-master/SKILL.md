# 外贸技能目录 · 内容生产

外贸技能库里归在「内容生产」的技能共 16 个。先按下表挑最贴近任务的一个，读它的 SKILL.md 再做；
几个都相关时先读描述最具体的那个。通用做法（工具替换、发信要人确认、数据落到工作区文件）见 `ft-conventions`。

| 技能 | 用途 |
|---|---|
| `ft-amazon-a-plus-content` | 亚马逊 A+ 页面策划与撰写：模块布局、卖点文案、对比图表、图片需求单与转化优化。 |
| `ft-amazon-enhanced-brand-content` | 亚马逊高级 A+ 与品牌故事：模块设计、场景图、对比图与移动端适配（仅能力提纲）。 |
| `ft-amazon-listing-images` | 亚马逊 Listing 图片策略：拍摄清单、信息图、场景图、移动端适配与图片测试。 |
| `ft-amazon-product-photography` | 亚马逊产品拍摄策划：把产品信息转成图片套组、拍摄清单、信息图与场景图需求单，并比较自拍/外包/AI 生成。 |
| `ft-ecommerce-content-marketing` | 电商内容营销规划：从评论、趋势、竞品内容与 SEO 机会提炼选题，生成分平台内容日历，或审计现有内容。 |
| `ft-ecommerce-video-marketing` | 电商视频营销：按漏斗阶段规划产品演示、开箱、UGC 与短视频，含各平台规格与视频 SEO（仅能力提纲）。 |
| `ft-etsy-listing-photography` | Etsy 商品拍摄：构图、光线、背景、修图、场景图与 360 视图（仅能力提纲）。 |
| `ft-etsy-product-description` | Etsy 商品描述写作：关键词融入、利益点文案、FAQ 与排版（仅能力提纲）。 |
| `ft-guarantee-proposal` | 商业提案生成：多角色协作产出战略建议书、商业计划书与投资回报方案，数字只用用户给的资料。 |
| `ft-product-description` | 产品高转化描述：按 FAB 方法生成 B2B 产品描述、销售资料与邮件段落，参数只用产品资料里有的。 |
| `ft-product-description-generator` | 全平台商品文案生成：竞品调研加关键词打分，用 FABE 写标题、五点、描述与后台关键词，或优化现有 Listing。 |
| `ft-shopify-blog-strategy` | Shopify 博客内容营销：SEO 文章、产品教育、选购指南与内链（仅能力提纲）。 |
| `ft-shopify-product-photography-guide` | DIY 产品拍摄：布景、光线、背景、修图、场景图与 360 视图（仅能力提纲）。 |
| `ft-shoppable-video` | 可购物视频：TikTok Shop、Reels、Shorts、Amazon Live 的商品标记、脚本、开头钩子与转化（仅能力提纲）。 |
| `ft-short-video` | 外贸短视频脚本：TikTok、YouTube Shorts、Instagram Reels 等平台的 B2B 产品短视频脚本与分镜。 |
| `ft-tiktok-shop-content-strategy` | TikTok Shop 内容策略：热门形式、爆款开头、产品展示、话题标签与内容日历。 |
