# 外贸技能目录 · 数据整理与市场数据

外贸技能库里归在「数据整理与市场数据」的技能共 7 个。先按下表挑最贴近任务的一个，读它的 SKILL.md 再做；
几个都相关时先读描述最具体的那个。通用做法（工具替换、发信要人确认、数据落到工作区文件）见 `ft-conventions`。

| 技能 | 用途 |
|---|---|
| `ft-b2b-global-strategy` | B2B 制造业出海战略：多平台竞品地图→竞争格局→切入策略→区域市场优先级→数字推广，按产品渠道（纯 B2B/加亚马逊/加独立站）裁剪。 |
| `ft-comtrade-market-data` | 联合国贸易统计取数：国家对国家进出口额、单价、双边矩阵、贸易差额、热门商品，用于选目标市场；不含买家名称。 |
| `ft-customs-data` | 海关数据分析：进出口记录查询思路、采购商筛选、采购频次与市场趋势解读，没有数据就明说不编造。 |
| `ft-daily-automation` | 外贸定时任务：早安简报、日报周报、定时发布与自动化工作流的设计，交给本产品定时任务执行，对外发送仍由人确认。 |
| `ft-inquiry-meeting` | 询盘分析会主持：按周复盘询盘来源、质量、转化与卡点，输出销售主管可直接开会用的材料。 |
| `ft-market-analysis` | 目标市场分析与作战地图：目标国认证要求、关税政策、关键词武器库、3 秒钩子等系统化市场进入策略。 |
| `ft-product-outbound-market-analysis` | 产品出海市场分析：某产品进入目标国家/地区的公开价格、趋势、准入认证、关税、出口要求与物流，只出带来源的客观事实矩阵，不给进入建议。 |
