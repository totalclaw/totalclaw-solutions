# Skill: 目标人群深度心理画像（Psychographic Profiling）

> 由 `/osint` 命令自动加载（类型：`psychograph`）
> 核心哲学：行为画像告诉你"他们做什么"，心理画像告诉你"为什么做"以及"怎么打动他们"。

## 定位

不同于 `osint-persona.md`（按行为聚类的买家角色卡片），本 skill 聚焦于：
- **一个目标群体**的集体心理结构（如"25-50岁外贸老板"、"DTC品牌创始人"、"采购经理"）
- 输出可直接驱动**内容营销、品牌定位、销售话术、产品设计**的心理洞察

## 前提条件

用户需指定：
- **目标人群定义**（行业 + 角色 + 年龄/阶段等特征）
- **分析目的**（品牌定位 / 内容策略 / 销售话术 / 产品设计 / 综合）

## PIR 清单

1. **他们的世界长什么样？** 业务环境、日常节奏、核心压力源
2. **水面之下藏着什么？** 未说出口的恐惧、矛盾、渴望
3. **什么能瞬间击中他们？** 情感触发点、集体认同密码
4. **什么是他们真正相信的？** 价值排序、理想状态、社会期望的张力
5. **一句话怎么说才对？** 可传播的核心命题和表达方式

---

## 五阶段分析框架

```
Stage 1: 表层认知采集 → 他们说什么、要什么、被怎么看
Stage 2: 潜意识解构   → 他们怕什么、纠结什么、不敢说什么
Stage 3: 情感维度解析 → 什么能让他们瞬间共鸣
Stage 4: 价值观解构   → 他们真正相信什么、最终想要什么
Stage 5: 洞察提炼     → 3个痛点观点 + 1个核心命题 + 1个传播公式
```

## Stage 1: 表层认知采集

> 目标：画出这个群体的"官方版自画像"——他们公开表达的需求和困境。

### 采集清单

| 采集项 | 数据来源 | 工具 |
|--------|---------|------|
| **显性业务目标**（前3个）| 行业报告、招聘JD、论坛帖子 | WebSearch + WebFetch |
| **日常高频抱怨**（前3个）| 社交媒体（小红书/知乎/LinkedIn）、行业论坛、评论区 | WebSearch + firecrawl_search |
| **社会标签与刻板印象** | 媒体报道、社交平台讨论、影视/综艺形象 | WebSearch |
| **行业宏观环境** | 政策报告、行业协会数据、经济分析 | WebSearch + WebFetch |

### 搜索策略

```
# 显性诉求
WebSearch: "[目标群体] 最大的困难/挑战 site:zhihu.com"
WebSearch: "[目标群体] 痛点 site:xiaohongshu.com"
WebSearch: "[行业] business challenges [年份] survey"

# 日常抱怨
WebSearch: "[目标群体] 吐槽 site:zhihu.com OR site:douban.com"
WebSearch: "[目标群体] 最烦的事"
WebSearch: "r/[相关subreddit] biggest frustration [角色]"

# 社会印象
WebSearch: "[目标群体] 真实生活 vs 外人以为"
WebSearch: "[目标群体] 刻板印象"
```

## Stage 2: 潜意识解构

> 目标：穿透"官方版"，找到他们不会主动说但真实存在的恐惧、矛盾和渴望。

### 采集策略

潜意识层面的信息不会直接出现在调查问卷里，需要从以下间接来源推断：

| 信号类型 | 数据来源 | 推断逻辑 |
|---------|---------|---------|
| **匿名表达** | 知乎匿名回答、Reddit throwaway、脉脉匿名区 | 匿名时说的 ≈ 真实想法 |
| **深夜/情绪化内容** | 社交媒体按时间筛选、情绪帖子 | 防线最低时的表达最真实 |
| **离场者的声音** | "我为什么离开[行业]"类帖子、转行经验分享 | 离开的原因 = 留下来的人也在忍受但没说的 |
| **伴侣/家人视角** | "[目标群体]的老婆/老公怎么看" 类讨论 | 旁观者看到的盲区 |
| **职业倦怠/中年危机帖** | 心理咨询相关讨论、自我怀疑类内容 | 深层恐惧和矛盾 |
| **消费行为异常** | 高端消费 vs 生活品质、焦虑消费模式 | 用消费行为补偿的心理需求 |

### 搜索策略

```
# 深层恐惧
WebSearch: "[目标群体] 最怕什么 site:zhihu.com"
WebSearch: "[目标群体] 焦虑 失眠 压力"
WebSearch: "[目标群体] 中年危机"
WebSearch: "为什么离开[行业] 后悔"

# 内心矛盾
WebSearch: "[目标群体] 纠结 放弃还是坚持"
WebSearch: "[目标群体] 家庭 事业 平衡"
WebSearch: "[目标群体] 想做但不敢"

# 未说出口的渴望
WebSearch: "[目标群体] 如果重来 会选择"
WebSearch: "[目标群体] 理想生活"
WebSearch: "[目标群体] 最羡慕"
```

### Stage 2 分析框架

对采集到的内容进行三层分析：

**层1：深层恐惧识别**
- 从表面诉求反推：他们要X → 是因为怕失去Y
- 公式：`[显性目标] 背后的真实恐惧 = [如果失去X会怎样？]`

**层2：核心矛盾映射**
- 识别至少3对内心矛盾（A vs B 的张力）
- 每对矛盾必须有真实的两面证据，不是臆测

**层3：未说出口的渴望**
- 从"如果没有约束"类讨论中提取
- 从"离场者选择了什么"反推留下来的人缺什么

### Stage 2 输出模板

```markdown
## 第二阶段：潜意识解构

### 4. 表象之下的深层恐惧
| 显性诉求 | 背后的真实恐惧 | 证据来源 |
|---------|--------------|---------|
| [要稳定增长] | [怕被市场淘汰/怕企业死掉] | [具体引用] |
| [要降成本] | [怕利润归零、财务崩溃] | [具体引用] |
| [要信息] | [怕决策失误、怕落后于人] | [具体引用] |

### 5. 核心内心矛盾（至少3对）
1. **[A] vs [B]** — [描述这对矛盾的具体表现 + 两面证据]
2. **[A] vs [B]** — [描述]
3. **[A] vs [B]** — [描述]

### 6. 未说出口的内心渴望（Top 3）

3. **[渴望]** — ...
```

## Stage 3: 情感维度解析

> 目标：找到能瞬间穿透理性防线、引发集体共鸣的情感触发点。

### 采集策略

| 信号类型 | 数据来源 | 分析方法 |
|---------|---------|---------|
| **高互动内容** | 社交媒体点赞/评论/转发最高的帖子 | 什么内容让他们忍不住互动？ |
| **评论区金句** | 热门帖子的评论区 | 评论比原帖更真实——他们用什么词回应？ |
| **行业梗/暗语** | 群体内部的特定用语、段子 | 只有圈内人懂的表达 = 身份认同密码 |
| **泪点/怒点内容** | 情绪极值的帖子和讨论 | 什么让他们破防？ |
| **仪式性时刻** | 行业特定的共同经历（如广交会、黑五） | 共同记忆 = 集体认同的锚点 |

### 搜索策略

```
# 高共鸣内容
WebSearch: "[目标群体] 扎心 真实 site:xiaohongshu.com"
WebSearch: "[目标群体] 看哭了 太真实了"
WebSearch: "[行业] meme jokes Reddit"

# 集体认同
WebSearch: "[目标群体] 只有我们才懂"
WebSearch: "[目标群体] 日常 真实版"
WebSearch: "[行业] things only [角色] understand"

# 情感极值
WebSearch: "[目标群体] 崩溃 瞬间"
WebSearch: "[目标群体] 最有成就感的时刻"
```

### Stage 3 分析框架

**情感触发点分类**

| 触发类型 | 定义 | 典型场景 | 传播效果 |
|---------|------|---------|---------|
| **孤独共鸣** | "原来不只我一个人这样" | 决策孤独、深夜加班、无人理解 | 极高——共鸣=转发 |
| **委屈释放** | "终于有人替我说了" | 被误解、被低估、付出不被看见 | 高——情绪宣泄 |
| **身份骄傲** | "这就是我们" | 行业特有技能、共同经历、专业自豪 | 高——圈层传播 |
| **时间焦虑** | "来不及了" | 错过家庭、健康透支、青春流逝 | 中高——引发反思 |
| **反差真实** | "你以为的vs真实的" | 外人眼中光鲜 vs 实际辛酸 | 极高——打破滤镜 |

## Stage 4: 价值观解构

> 目标：理解他们的终极信念体系——什么排在什么前面，理想与现实的落差在哪里。

### 采集策略

| 信号类型 | 数据来源 | 推断逻辑 |
|---------|---------|---------|
| **长文/深度访谈** | 播客、深度采访、个人公众号 | 长内容暴露真实价值观 |
| **二选一困境** | 论坛讨论中的选择题 | 选A还是B暴露优先级 |
| **人生转折叙事** | "我为什么做这个决定"类内容 | 关键决策暴露核心价值 |
| **英雄/偶像选择** | 他们推崇谁？读什么书？ | 崇拜对象 = 理想自我投射 |
| **遗憾/后悔表达** | "如果重来我会..."类讨论 | 后悔的反面 = 真正重要的 |

### 搜索策略

```
# 价值排序
WebSearch: "[目标群体] 最重要的 选择"
WebSearch: "[目标群体] 后悔 如果重来"
WebSearch: "[目标群体] 成功的定义"

# 社会期望张力
WebSearch: "[目标群体] 不想做但必须做"
WebSearch: "[目标群体] 别人以为我很[X] 其实"

# 理想状态
WebSearch: "[目标群体] 理想生活 退休后想"
WebSearch: "[目标群体] 如果不做[行业] 会做什么"
```

### Stage 4 分析框架

**价值排序推断法**

从行为和选择中推断，而不是从他们的自我描述中接受：

```
他们说最重要的 ≠ 真正最重要的
真正最重要的 = 当两个价值冲突时，他们牺牲哪个保哪个？

例：口头说"家庭第一" → 但实际上周末加班、假期看邮件
     → 真实排序：事业安全感 > 家庭陪伴时间
     → 但这不代表家庭不重要，而是恐惧驱动的优先级
```

**社会期望 vs 个人意愿的张力矩阵**

| 维度 | 社会期望（"应该"） | 个人意愿（"想要"） | 张力程度 |
|------|------------------|------------------|---------|
| 规模 | 做大做强 | 可能想做精做稳 | ? |
| 形象 | 光鲜成功 | 可能想低调简单 | ? |
| 节奏 | 拼搏奋斗 | 可能想平衡休息 | ? |
| 成就 | 商业指标 | 可能想生活品质 | ? |

## Stage 5: 洞察提炼

> 目标：把4个阶段的分析浓缩为可直接使用的营销/销售/品牌洞察。

### 提炼规则

**3个痛点观点** — 每个必须满足：
- 来自 Stage 2（恐惧/矛盾）和 Stage 3（情感触发）的交叉点
- 能用一句话表达
- 听到后的第一反应是"说的就是我"而不是"有道理"
- 情感穿透力 > 逻辑说服力

**1个核心命题** — 必须满足：
- 重新定义该群体对"成功"或"解决方案"的认知
- 既挑战现状，又提供出路
- 能成为品牌/内容的长期主线

**1个传播公式** — 必须满足：
- 包含具体场景（不是抽象概念）
- 使用群体特有的语言/意象
- 制造"反差"或"破防"效果
- 长度 ≤ 80字（适合社交媒体单条传播）

### 传播公式结构

```
[具体场景] + [反差/揭示] + [情感落点]

好的例子："凌晨三点的邮件，西装下的疲惫，和只有我们懂的交期焦虑——
          不是所有的辛苦，都能被利润表理解。"

结构拆解：
- 具体场景：凌晨三点的邮件
- 反差：西装（外在光鲜）vs 疲惫（内在真实）
- 行业密码：交期焦虑（只有圈内人懂）
- 情感落点：付出不被看见的委屈
```

### Stage 5 输出模板

```markdown
## 第五阶段：洞察提炼

### 3个最能戳中痛点的观点
1. **"[观点1]"** — 戳中的点：[来自哪个恐惧/矛盾] — 适用场景：[内容/广告/销售]
2. **"[观点2]"** — 戳中的点：[...] — 适用场景：[...]
3. **"[观点3]"** — 戳中的点：[...] — 适用场景：[...]

### 1个能引发集体共鸣的核心命题
> "[命题]"
>
> 为什么有效：[分析——重新定义了什么？挑战了什么假设？提供了什么出路？]
> 适用方向：[品牌slogan / 内容主线 / 演讲主题 / 销售定位]

### 1个传播公式
> "[≤80字的表达]"
>
> 结构拆解：
> - 具体场景：[...]
> - 反差/揭示：[...]
> - 行业密码：[...]
> - 情感落点：[...]
>
> 预期效果：[为什么这个表达会被转发/收藏/截图]
```

## 应用联动

### → 与 Persona 联动

心理画像为每个 Persona 卡片提供"灵魂层"：

| Psychograph 输出 | 映射到 Persona 字段 |
|-----------------|-------------------|
| Stage 2 深层恐惧 | Persona → 心理驱动力 |
| Stage 3 情感触发点 | Persona → 沟通钩子 |
| Stage 4 价值排序 | Persona → 决策权重 |
| Stage 5 痛点观点 | Persona → 价值主张角度 |

### → 与 Sales Playbook 联动

| Psychograph 输出 | 映射到 Playbook 模块 |
|-----------------|-------------------|
| Stage 2 未说出口的渴望 | 模块 3: 价值主张的情感层 |
