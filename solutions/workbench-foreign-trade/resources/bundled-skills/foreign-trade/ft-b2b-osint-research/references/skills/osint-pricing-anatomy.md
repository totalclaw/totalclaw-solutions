# Skill: 定价与利润结构拆解（Pricing & Margin Anatomy）

> 由 `/osint` 命令在 company/competitor 调查中加载（DTC品牌/分销商/制造商通用）
> 核心哲学：价格倍率决定企业生死。中国制造成本的3倍是地狱，5倍是生存，8倍是舒适，10倍以上才是安全。

## 为什么价格倍率是最重要的单一指标

```
一个产品从中国工厂到消费者手中的价格链：

中国FOB成本 $10
  × 倍率 → 终端零售价

3x ($30)  = 💀 地狱模式 — 扣除运费/关税/仓储/营销后几乎无利润
              只能靠极大销量+极低运营成本生存
              中国电商品牌的内卷区间

5x ($50)  = 😐 生存模式 — 能运行但不舒服
              一次退货/一次广告ROI下降就亏损
              大多数跨境电商品牌在此区间

8x ($80)  = 😊 舒适模式 — 有足够利润做品牌/合规/扩张
              可以承受退货、客服、线下渠道成本
              成熟DTC品牌的目标区间

10x+ ($100+) = 🏰 安全模式 — 品牌溢价+渠道利润+全球化运营
                可以养活经销商网络、做线下零售、合规地运营
                西方成熟品牌的常见区间

关键洞察：
- 足够的利润才能让公司"安全又合规"
- 利润不是贪婪，是运营全球业务的必要条件
- 中国品牌的10x价差 → 正是全球化运营的最佳空间
- 人均产值可以直接反映一家公司是否在健康倍率区间
```

## 一、价格瀑布模型（Price Waterfall）

> 从工厂到消费者，每一层的加价和成本。

### 完整价格瀑布

```
┌─────────────────────────────────────────────────────────────┐
│ 层级 0: 中国 BOM 成本（Bill of Materials）                    │
│ • 原材料 + 零部件 + 组装人工                                  │
│ • 示例: 太阳能板 BOM = $15                                    │
├──────────────────────────── ×1.15-1.25 ────────────────────┤
│ 层级 1: FOB 出厂价（工厂利润 + 包装 + 出口费用）              │
│ • 工厂毛利 15-25%                                             │
│ • 示例: FOB = $18                                             │
├──────────────────────────── ×1.20-1.40 ────────────────────┤
│ 层级 2: 到岸成本（Landed Cost）                               │
│ • 海运/空运 + 关税(0-25%+) + 清关 + 保险                     │
│ • 2025-2026关税变化: 中国商品可能被征25-60%额外关税            │
│ • 示例: Landed = $25                                          │
├──────────────────────────── ×1.10-1.25 ────────────────────┤
│ 层级 3: 仓储到门成本（Warehouse + Last Mile）                 │
│ • 3PL仓储 + 入库 + 拣货包装 + 最后一公里运费                  │
│ • FBA费用: 通常15-20%的售价                                   │
│ • 示例: 仓储到门 = $30                                        │
├──────────────────────────── 品牌方定价决策线 ──────────────┤
│ 层级 4: 品牌方定价（Brand Selling Price / Wholesale Price）    │
│ • 品牌需覆盖: 营销(15-30%) + 客服(3-5%) + G&A(8-15%)         │
│ •            + 退货(5-15%) + 合规(2-5%) + 净利润(5-15%)      │
│ • DTC售价 或 批发给分销商的价格                                │
├──────────────────────────── ×1.25-1.40 ────────────────────┤
│ 层级 5: 分销商加价（Distributor Markup 20-40%）               │
│ • 分销商需覆盖: 仓储+物流+销售团队+信用风险                   │
│ • 行业标准: 分销商毛利 20-25%                                 │
├──────────────────────────── ×1.40-2.00 ────────────────────┤
│ 层级 6: 零售商加价（Retailer Markup 40-100%）                 │
│ • 零售商需覆盖: 店面+人工+库存风险+促销                       │
│ • 行业标准: 零售商毛利 40-50%（电子产品）/50-70%（服饰）      │
├──────────────────────────── = 最终价格 ────────────────────┤
│ 层级 7: MSRP（消费者支付价格）                                 │
│ • 示例: MSRP = $99（从FOB $18 → 5.5x 倍率）                  │
└─────────────────────────────────────────────────────────────┘
```

### 不同渠道的价格瀑布对比

| 层级 | DTC直销 | Amazon FBA | 分销→零售 | B2B批发 |
|------|---------|-----------|-----------|---------|
| BOM | $15 | $15 | $15 | $15 |
| FOB | $18 | $18 | $18 | $18 |
| Landed | $25 | $25 | $25 | $25 |
| 平台/仓储费 | $5 (3PL) | $15 (FBA 15%) | $5 (分销仓) | $2 |
| **品牌获得** | **$69** | **$50** | **$35** | **$30** |
| 分销商 | — | — | $50 | — |
| 零售商 | — | — | $99 | — |
| **消费者支付** | **$99** | **$99** | **$99** | **$30** |
| **品牌毛利** | **$44 (64%)** | **$25 (50%)** | **$10 (29%)** | **$5 (17%)** |
| **FOB倍率** | **5.5x** | **5.5x** | **5.5x** | **1.7x** |

**关键洞察**：
- 同一个MSRP $99，品牌通过DTC拿到$69，通过分销只拿到$35
- 这就是为什么中国品牌先做DTC（Amazon+官网），再慢慢建分销
- B2B批发利润最薄（1.7x），但量大且现金流稳定

## 三、西方 DTC 品牌运营模型拆解

### 成本结构（典型西方DTC品牌 P&L）

```
                    中国DTC品牌      西方DTC品牌      差异原因
                    ──────────      ──────────      ─────────
营收                $10M (100%)     $10M (100%)
─────────────────────────────────────────────────────────
COGS (到岸成本)     40-50%          25-35%          西方品牌倍率高→COGS占比低
毛利率              50-60%          65-75%          ← 倍率差异的直接体现
─────────────────────────────────────────────────────────
营销/获客            25-35%          20-30%          西方品牌已有品牌认知
  - Amazon PPC       15-20%          5-10%          西方品牌不依赖Amazon
  - 社媒/KOL          5-10%          8-15%          西方品牌更重社媒
  - PR/品牌           1-3%           3-8%           西方品牌更重PR
物流/履约             8-12%          8-12%          相近（都用3PL/FBA）
客服/售后             3-5%           5-8%           西方品牌投入更多
G&A (管理开支)        5-8%           10-18%         西方人工成本是核心差异
  - 人工成本          3-5%           8-15%          ← 美国人工 = 中国的5-10x
  - 办公/合规         2-3%           3-5%           合规成本更高
退货/损耗             3-8%           5-10%          西方消费者退货率更高
─────────────────────────────────────────────────────────
EBITDA              3-8%            5-15%           西方品牌因倍率高→净利更高
净利润              1-5%            3-12%           中国品牌利润薄但增速快
─────────────────────────────────────────────────────────
关键差异:
人工成本占营收比      3-5%            8-15%          最大单项差异
人均薪资             $15-30K         $80-150K        5-10x 差距
员工数(同营收)        50-100人        15-30人         中国人多但便宜
人均产值             $100-200K       $333-667K       西方人少但贵
```

### 西方 DTC 品牌的7个核心特征

| # | 特征 | 描述 | 对你的启示 |
|---|------|------|-----------|
| 1 | **高倍率定价** | MSRP通常是中国品牌的1.5-3倍 | 你有空间做中间定位 |
| 2 | **品牌叙事驱动** | 故事/使命/社区 > 参数/价格 | 品牌投资是长期护城河 |
| 3 | **渠道利润养分销** | 留足利润给经销商/零售商 | 这就是为什么他们能进Costco |
| 4 | **合规是门票** | UL/FCC/EPA/CSA认证齐全 | 没有合规就没有线下渠道 |
| 5 | **售后是品牌** | 客服投入5-8%营收 | 售后体验 = 复购 + 口碑 |
| 6 | **慢增长稳利润** | 年增10-20%，EBITDA 10-15% | 不追求爆发，追求持续 |
| 7 | **退出策略清晰** | 被大公司收购(Goal Zero→NRG) | 品牌是资产，可以卖 |

### 关键发现

```
西方品牌人均产值 $400K-$1200K
中国品牌人均产值 $100K-$300K

但这不代表西方品牌"更好"——
西方: 少人 × 高薪 × 高倍率 = 高人均产值
中国: 多人 × 低薪 × 低倍率 = 低人均产值

真正的问题是：
你能不能用 中国成本 + 西方倍率 = 超级人均产值？

答案：可以，但需要品牌+合规+渠道。
目标: $5-10M / 2-3人 = $2-5M人均产值（远超两端）
```

## 四、经销商/分销商运营策略拆解

### 价格阶梯模型（Price Tier Structure）

```
┌──────────────────────────────────────────────────────────┐
│ 价格阶梯（以太阳能面板为例，MSRP = $150）                  │
│                                                            │
│ MSRP (建议零售价)         $150  ← 消费者看到的价格          │
│   ↑ 零售商毛利 40%                                         │
│ MAP (最低广告价)          $135  ← 不得低于此价格宣传         │
│   ↑ 促销/季节折扣空间                                       │
│ 零售商采购价              $90   ← 零售商从分销商买入         │
│   ↑ 分销商毛利 25%                                         │
│ 分销商采购价              $68   ← 分销商从品牌方买入         │
│   ↑ 品牌方毛利 55%                                         │
│ 品牌方到岸成本            $30   ← FOB + 运费 + 关税         │
│   ↑ 工厂毛利 20%                                           │
│ 中国FOB出厂价             $18   ← 工厂成本                  │
│   ↑ 制造成本                                                │
│ BOM成本                   $15   ← 原材料+人工               │
└──────────────────────────────────────────────────────────┘

倍率: MSRP $150 / FOB $18 = 8.3x ← 这是"舒适区间"
品牌方利润: ($68 - $30) / $68 = 56% 毛利
分销商利润: ($90 - $68) / $90 = 24% 毛利
零售商利润: ($150 - $90) / $150 = 40% 毛利
```

### 渠道定价策略类型

| 策略 | 描述 | 适用 | 品牌例子 |
|------|------|------|---------|
| **MAP政策** | 设定最低广告价，保护渠道利润 | 有品牌力的产品 | Goal Zero, YETI |
| **排他性分销** | 限定区域/渠道只有1个分销商 | 高端/专业产品 | Victron Energy |
| **分级折扣** | 按采购量给不同折扣（T1/T2/T3） | 规模化分销 | Renogy Dealer Program |
| **DTC+分销平行** | 官网DTC与分销商并行 | DTC为主的品牌 | EcoFlow, Anker |
| **纯分销** | 品牌不直接卖终端 | 工业/专业品类 | Victron Energy |
| **零售独家** | 与单一零售商签独家 | 追求渠道稳定 | Milwaukee→Home Depot |

### 分销商利润健康度评估

| 指标 | 危险 | 紧张 | 健康 | 优秀 |
|------|------|------|------|------|
| 分销商毛利 | <15% | 15-20% | 20-30% | >30% |
| MAP保护 | 无MAP | 有MAP不执行 | 有MAP严格执行 | MAP+渠道独家 |
| 最低起订量 | >$50K | $20-50K | $5-20K | <$5K |
| 账期 | 预付100% | Net 30 | Net 45-60 | Net 90 |
| 退换政策 | 不退 | 有限退换 | 完整退换 | 退换+换季清库存 |
| 营销支持 | 无 | 素材共享 | Co-op广告基金 | 全套市场支持 |

## 五、人均产值健康度模型

> 人均产值 = 年营收 ÷ 全职员工数。这是判断企业运营效率最直接的指标。

### 人均产值基准表

| 行业/类型 | 亏损线 | 生存线 | 健康线 | 优秀线 | 顶级 |
|-----------|--------|--------|--------|--------|------|
| **消费电子DTC** | <$100K | $100-200K | $200-400K | $400-800K | >$800K |
| **工业设备** | <$150K | $150-300K | $300-500K | $500K-1M | >$1M |
| **SaaS** | <$100K | $100-200K | $200-400K | $400-800K | >$1M |
| **服饰/时尚DTC** | <$80K | $80-150K | $150-300K | $300-500K | >$500K |
| **食品/CPG** | <$150K | $150-300K | $300-500K | $500-800K | >$800K |

### 人均产值诊断

```
人均产值 = 营收 / 员工数

诊断:
< $100K → 💀 严重亏损或效率极低
          可能原因: 过度招聘 / 产品定价过低 / 增长停滞

$100-250K → 😐 中国品牌常见区间
            代表: Renogy ($250K), BougeRV (~$250K)
            问题: 人多但利润薄，抗风险能力弱

$250-500K → 😊 健康运营
            代表: Jackery ($500K), Enphase ($719K)
            状态: 有余力做品牌投入和渠道建设

$500K-1M  → 🏰 高效运营
            代表: Goal Zero (~$700K), YETI ($1231K)
            特征: 高倍率 + 精简团队 + 品牌溢价

> $1M     → 👑 极致效率
            代表: YETI ($1231K), 你的AI目标($3M+)
            要么极强品牌力，要么极致自动化

极致效率目标（AI驱动）:
$5M / 2人 = $2.5M人均产值 → 超越所有传统品牌
```

### 人均产值 × 倍率 交叉分析

| | 低倍率(3-5x) | 中倍率(5-8x) | 高倍率(8x+) |
|---|-------------|-------------|------------|
| **低人均产值(<$200K)** | 💀 中国白牌内卷 | ⚠️ 增长期中国DTC | 罕见 |
| **中人均产值($200-500K)** | 😐 中国成熟DTC | 😊 健康品牌 | 🏰 精品品牌 |
| **高人均产值(>$500K)** | 罕见 | 🏰 高效DTC | 👑 品牌垄断 |

**最佳甜蜜点: 中倍率(5-8x) × 高人均产值(>$500K)**
= 中国成本结构 + 品牌溢价 + 运营效率

## 六、中国品牌 vs 西方品牌定价差异根因

### 为什么西方品牌能卖10倍价格？

| # | 成本项 | 西方品牌 | 中国品牌 | 倍数 | 说明 |
|---|--------|---------|---------|------|------|
| 1 | **人工** | $80-150K/人/年 | $8-30K/人/年 | 3-15x | 最大单项差异 |
| 2 | **办公** | $40-80/sqft/年 | $5-15/sqft/年 | 5-10x | 硅谷/纽约 vs 苏州/深圳 |
| 3 | **合规** | $50-200K/年 | $5-20K/年 | 5-10x | UL/FCC/EPA认证+律师 |
| 4 | **保险** | $20-100K/年 | $2-10K/年 | 5-10x | 产品责任险+运营险 |
| 5 | **税负** | 25-40%有效税率 | 15-25%有效税率 | 1.5-2x | 联邦+州税 vs 高新企业优惠 |
| 6 | **营销** | $15-30 CAC | $5-15 CAC | 2-3x | 英文市场竞争更激烈 |
| 7 | **客服** | $25-35/小时/人 | $5-10/小时/人 | 3-5x | 母语客服 vs 外语客服 |
| 8 | **退货** | 8-15%退货率 | 3-8%退货率 | 2x | 西方消费者退货习惯 |

### 总成本对比（同营收$10M）

```
                    西方品牌          中国品牌
                    ────────          ────────
营收                $10M              $10M
COGS               $2.5M (25%)       $4.5M (45%)    ← 中国品牌倍率低→COGS占比高
毛利               $7.5M (75%)       $5.5M (55%)

运营成本:
```

## 七、你的定价策略选择框架

### 三种定价模式

| 模式 | 定价策略 | 倍率 | 人均产值目标 | 适合 | 风险 |
|------|---------|------|------------|------|------|
| **A: 价格破坏** | 比西方品牌低30-50% | 5-6x | $500K+ | 有供应链优势+AI效率 | 中国品牌跟进打价格战 |
| **B: 价值中间** | 与西方品牌持平，功能多50% | 6-8x | $1M+ | 有差异化技术/设计 | 需要品牌投入时间 |
| **C: 品牌溢价** | 与西方品牌持平或更高 | 8-12x | $2M+ | 有独特品牌故事/渠道 | 需要长期品牌建设 |

### 定价决策树

```
你的产品中国FOB成本是多少？
│
├── FOB < $20（低值产品：线材/配件/小面板）
│   → 必须走 8-15x 倍率才有利润空间
│   → DTC优先（Amazon/官网），不走分销
│   → 参考: Anker充电器 FOB $3 → 零售 $25-40 (8-13x)
│
├── FOB $20-100（中值产品：面板/小电站/电池）
│   → 5-8x 倍率是甜蜜点
│   → DTC + 分销并行
│   → 参考: Renogy 100W面板 FOB ~$18 → DTC $79 (4.4x) / 零售$120 (6.7x)
│
├── FOB $100-500（高值产品：大电站/储能系统）
│   → 3-5x 倍率也能活（绝对利润够）
│   → 分销+B2B为主
│   → 参考: EcoFlow Delta Pro FOB ~$300 → DTC $1799 (6x)
│
└── FOB > $500（系统级：全屋储能/太阳能系统）
    → 2-4x 倍率+安装服务利润
    → B2B/安装商网络
    → 参考: Enphase系统 成本$2000 → 安装价$8000 (4x)
```

## 八、数据采集清单（定价拆解用）

> 调查任何公司时，以下数据点用于完成定价拆解。

### 产品端
- [ ] **Amazon价格** — 主力SKU的当前售价
- [ ] **官网DTC价格** — 同SKU的官网价（通常≥Amazon）
- [ ] **Keepa价格历史** — 历史最低/最高/均价
- [ ] **竞品同类价格** — 3-5个竞品的同规格产品价格
- [ ] **分销/Dealer价格** — Dealer网站或B2B平台可见价格（如有）
- [ ] **MAP价格** — 是否有MAP政策？MAP是MSRP的多少？

### 成本端
- [ ] **1688/阿里巴巴报价** — 同类产品的中国出厂报价（代理FOB参考）
- [ ] **ImportYeti HS编码** — 确定关税税率
- [ ] **物流成本估算** — 海运/空运 + FBA费用

### 倍率计算
- [ ] **FOB→DTC倍率** = DTC售价 ÷ 估算FOB
- [ ] **FOB→零售倍率** = 零售价 ÷ 估算FOB
- [ ] **倍率健康度判断** — 对照倍率诊断矩阵

### 渠道端
- [ ] **有无Dealer Program** — 官网搜索 dealer/partner/pro/wholesale
- [ ] **有无MAP政策** — Google搜索 "[品牌] MAP policy"
- [ ] **线下零售** — 是否在Costco/Home Depot/Best Buy/REI等
- [ ] **B2B/OEM** — 是否接受白标/代工

### 人效端
- [ ] **年营收** — 多来源交叉估算
- [ ] **员工数** — LinkedIn/ZoomInfo
- [ ] **人均产值** — 营收÷员工数
- [ ] **人均产值健康度** — 对照基准表

## 九、脉弱交叉分析（定价维度）

| # | 交叉维度 | 逻辑 | 信号 |
|---|---------|------|------|
| 1 | **低倍率 × 高营销投入** | 倍率<4x + Amazon PPC占比>20% | 🔥 不可持续，广告费吃掉利润 |
| 2 | **高倍率 × 无MAP** | 倍率>8x + 无MAP政策 | ⚠️ 渠道价格混乱，分销商可能串货 |
| 3 | **低人均产值 × 大量招聘** | <$200K + 大量招人 | 🔥 烧钱扩张，效率未提升 |
| 4 | **DTC价格 < 分销价** | 官网价低于分销商零售价 | 🔥 渠道冲突，分销商会流失 |
| 5 | **高退货率 × 低客服投入** | 差评多退货 + 客服仅占2-3% | ⚠️ 恶性循环，退货成本侵蚀利润 |
| 6 | **中国品牌 × 8x+倍率** | 中国供应链 + 高倍率 | ✅ 甜蜜点，有空间做品牌+合规 |
| 7 | **西方品牌 × <5x倍率** | 高成本结构 + 低倍率 | 🔥 利润危机，可能被中国品牌挤出 |
| 8 | **人均产值下降 × 倍率不变** | 效率降低但定价未调整 | ⚠️ 管理问题，成本在膨胀 |
