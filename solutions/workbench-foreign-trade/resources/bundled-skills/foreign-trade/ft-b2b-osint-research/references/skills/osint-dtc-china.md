# Skill: 中国出海 DTC 品牌运营拆解（China DTC Brand Anatomy）

> 由 `/osint` 命令在 company/competitor 调查中自动加载（当目标为中国出海品牌时）
> 核心哲学：他们的运营模式是可复制的公式，不是魔法。拆解公式，找到你能复制的环节。

## 为什么要拆解中国 DTC 品牌

```
2020-2026 趋势：
- 中国出海品牌从"卖货"进化到"建品牌"
- 安克从$100M到$3.4B，用了10年
- SHEIN从0到$45B，用了12年
- EcoFlow 3年拿下便携储能30%份额

共同点：
- 都有中国供应链优势（成本/速度/弹性）
- 都经历了 Amazon → DTC → 多渠道 的进化路径
- 都在特定阶段用了相似的战术组合

你的机会：
- 他们验证了哪些品类和市场是可行的
- 他们的运营模式可以被更精简地复制
- 他们做到10亿的团队规模，你用AI可以做到1亿的效果
```

## 一、品牌进化阶段模型（Stage Model）

> 判断目标品牌处于哪个阶段，决定你的应对策略。

```
┌─────────────────────────────────────────────────────────┐
│  Stage 0: 铺货卖家（Seller）                              │
│  特征: 多SKU、无品牌、低价、1688直发                        │
│  信号: 店铺名无辨识度、无官网、无社媒                        │
│  你的策略: 忽略，这不是竞争对手                              │
├─────────────────────────────────────────────────────────┤
│  Stage 1: 品牌萌芽（Brand Seedling）                      │
│  特征: 有品牌名、Amazon为主、开始做独立站                    │
│  信号: 官网简陋但有、社媒有但低活跃、SKU < 30               │
│  你的策略: 同阶段竞争，拼效率和选品                          │
├─────────────────────────────────────────────────────────┤
│  Stage 2: 渠道扩张（Channel Expansion）                   │
│  特征: Amazon + DTC + 线下试点、招Sales/BD                 │
│  信号: Shopify Plus / BigCommerce、开始投PR、SKU 30-100    │
│  你的策略: 跟进他们验证过的渠道，用轻资产复制                  │
├─────────────────────────────────────────────────────────┤
│  Stage 3: 多品牌矩阵（Multi-Brand Portfolio）             │
│  特征: 2-5个子品牌、品类扩展、开始做OEM                     │
│  信号: 多个独立品牌站、子品牌LinkedIn页面、OEM岗位            │
│  你的策略: 接他们的OEM/白标，或进入他们未覆盖的细分            │
├─────────────────────────────────────────────────────────┤
│  Stage 4: 生态系统（Ecosystem）                           │
│  特征: 硬件+软件+服务、App生态、用户社区                     │
│  信号: 自研App、IoT集成、大量Software Engineer招聘           │
│  你的策略: 做他们生态的配件/服务商，而非正面竞争               │
├─────────────────────────────────────────────────────────┤
│  Stage 5: 全球化巨头（Global Giant）                      │
│  特征: 多国本地化、上市/准上市、并购                         │
│  信号: 10+国家办公室、SEC filing、频繁并购新闻               │
│  你的策略: 做他们的供应商/分销商/服务商                       │
└─────────────────────────────────────────────────────────┘
```

### 维度 2: 渠道策略

| 渠道 | 作用 | 典型占比 | 数据采集 |
|------|------|---------|---------|
| **Amazon** | 现金流引擎 + 品牌曝光 | 40-70% | Amazon Store页面、BSR、评价数 |
| **DTC官网** | 利润中心 + 数据资产 | 15-35% | SimilarWeb流量、技术栈 |
| **线下零售** | 信任背书 + 增量 | 5-20% | Costco/Home Depot/Walmart搜索 |
| **B2B/OEM** | 产能利用 + 稳定现金流 | 5-15% | 招聘信号（OEM岗位） |
| **新兴市场** | 增长储备 | 0-10% | 多语言站点、区域招聘 |

**渠道进化路径判断**：
```
Amazon Only → Amazon + Shopify → Amazon + DTC + 线下试点
→ 全渠道 + B2B/OEM → 全球多站点

判断方法：
1. Amazon评价数 vs 官网流量比 → Amazon依赖度
2. 是否有 Dealer/Pro/Partner 页面 → B2B渠道是否启动
3. 是否在 Costco/Home Depot 等线下 → 线下渠道是否打通
4. 是否有多语言/多国站点 → 全球化进度
```

### 维度 3: 定价与产品策略

| 策略类型 | 特征 | 典型品牌 | 信号 |
|---------|------|---------|------|

- [ ] 新品上架频率（过去12个月新品数）
- [ ] 是否有"入门款→升级款→旗舰款"明确梯度

| # | 交叉维度 | 逻辑 | 信号 |
|---|---------|------|------|
| 1 | **关税政策 × 产地** | 100%中国制造 + 关税上涨 | 🔥 成本压力暴增，可能涨价或退出 |
| 2 | **Glassdoor × 中美架构** | "poor communication" + 双总部 | ⚠️ 管理效率低下，决策慢 |
| 3 | **Amazon依赖 × 差评趋势** | Amazon>70%收入 + 差评上升 | 🔥 平台风险极高，可能被降权 |
| 4 | **招聘急扩 × 现金流** | 大量招人 + 融资/亏损信号 | ⚠️ 烧钱扩张，可能不可持续 |
| 5 | **SKU膨胀 × 评价分散** | SKU多 + 多数评价<100 | ⚠️ 资源分散，无明星产品 |
| 6 | **专利少 × 高定价** | 专利<5 + 定价高于均价 | 🔥 品牌溢价无技术支撑，易被替代 |
| 7 | **供应商单一 × 销量高** | ImportYeti仅1-2家工厂 + 高BSR | ⚠️ 供应链脆弱，你可以找同工厂 |
| 8 | **中国运营 × 美国品牌** | 核心团队在中国 + 品牌定位美国 | ⚠️ 本地化深度不足，你有地利 |

## 八、与标杆对照速查

> 调查时快速对标，判断目标品牌在行业中的位置。

```
问题清单（每个回答 高/中/低）：

□ 技术壁垒: 专利数? 自研芯片/算法? → 对标 DJI(高) / BougeRV(低)
□ 品牌溢价: 能比同行贵多少? → 对标 DJI(+50%) / 铺货卖家(-30%)
□ 渠道多样性: 几个渠道? 依赖度? → 对标 Anker(全渠道) / 新品牌(Amazon Only)
□ 供应链控制: 自有工厂? 多少供应商? → 对标 Anker(自有) / 贸易商(0控制)
□ 本地化深度: 客服/内容/社区质量? → 对标 EcoFlow(高) / 多数中国品牌(低)
□ 增长阶段: 年增速? 扩张信号? → 对标 EcoFlow(>50%) / Jackery(<10%)
□ 抗风险能力: 关税/平台/供应链风险? → 对标 Anker(强) / 单品牌(弱)
```
