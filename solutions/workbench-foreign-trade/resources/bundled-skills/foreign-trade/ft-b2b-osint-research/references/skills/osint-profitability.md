# Skill: 产品盈利结构 & 财务健康度分析

> 由 `/osint` 命令在 company/competitor 类型调查中自动加载
> 核心哲学：一家公司的利润结构，决定了它能给你什么价格，以及你该从哪里切入。

## 适用场景

当调查目标为 **DTC品牌/零售商/分销商** 时，在基础调查完成后执行此分析。
回答核心问题：**他们靠什么赚钱？哪些产品有利润空间给分销商？**

## 一、产品线盈利分类

> 不是所有产品都赚钱。识别四类产品是谈判的基础。

### 四象限分类法

```
              高毛利
               │
    ┌──────────┼──────────┐
    │  🛡️ 护城河     │  🚀 利润引擎   │
    │  (专利/独家)   │  (新品/高端)   │
    │  低竞争      │  高溢价      │
    │  中等销量     │  高增长      │
    ├──────────┼──────────┤
    │  🐕 鸡肋       │  🧲 流量磁铁   │
    │  (长尾/配件)   │  (爆款/引流)   │
    │  低销量      │  高销量      │
    │  低关注度     │  零利润或亏损   │
    └──────────┼──────────┘
              低毛利
        低销量 ←────→ 高销量
```

### 数据采集方法

#### 来源 1: Amazon 产品页面分析
- [ ] **搜索品牌旗舰店** — `amazon.com/stores/[品牌名]`
- [ ] **按 BSR 排序** — 识别畅销品（BSR < 5000 = 高销量）
- [ ] **按价格排序** — 识别价格带分布
- [ ] **新品识别**:
  - 评价数 < 50 + 上架 < 6个月 = 新品
  - "New Release" 标签
  - 首条评价日期 → 推断上架时间
- [ ] **定价信号**:
  - 价格远低于同类 = 流量磁铁（如 $49.99 的 100W 太阳能板）
  - 价格远高于同类 = 品牌溢价/高端线
  - 频繁打折（Coupon/Lightning Deal）= 清库存或冲排名
  - 无折扣 + 高评分 = 利润产品

#### 来源 2: 官网 Shopify/DTC 分析
- [ ] **价格对比** — 官网 vs Amazon 价格差
  - 官网更高 → Amazon 是主渠道，官网做品牌
  - 官网更低 → 鼓励DTC直销，更高利润
  - 官网价 = Amazon价 → MAP（最低广告价格）政策
- [ ] **Bundle/套装** — 套装组合通常毛利更高（40-60%）
- [ ] **配件/耗材** — 利润率最高的产品线（如线缆、连接器、保护壳）
- [ ] **"New" / "Best Seller" 标签** — 官网产品分类信号
- [ ] **订阅/服务** — SaaS/App订阅 = 高毛利复购收入

#### 来源 3: 专利数据库（护城河识别）
- [ ] **USPTO 搜索** — `patents.google.com/?assignee=[公司名]`
  - 专利数量 → 研发投入指标
  - 专利类型：发明/外观/实用新型
  - 专利覆盖产品 → 定价权保护
- [ ] **专利诉讼** — 是原告还是被告？
  - 原告 = 在保护IP（好信号）
  - 被告 = 可能侵权（风险信号）

#### 来源 4: 卖家精灵 MCP（必做 — 替代估算，用实数据）

> 999元/年订阅，10000次/月查询额度。以下工具将估算升级为实数据。

## 二、财务健康度估算

> 私营公司没有财报？不重要。用公开数据 + 行业基准就能估算到八成准。

### 核心指标

#### 1. 人均产值（Revenue per Employee）

```
人均产值 = 年营收 / 全职员工数
```

**行业基准参考（年营收/人）**：

| 行业 | 卓越 | 优秀 | 良好 | 一般 | 差 |
|------|------|------|------|------|---|
| DTC 电商品牌 | >$500K | $300-500K | $200-300K | $100-200K | <$100K |
| 太阳能设备 | >$400K | $250-400K | $150-250K | $80-150K | <$80K |
| 硬件制造+DTC | >$350K | $200-350K | $120-200K | $80-120K | <$80K |
| 纯SaaS | >$300K | $200-300K | $150-200K | $100-150K | <$100K |
| 传统贸易 | >$800K | $500-800K | $300-500K | $150-300K | <$150K |

**上市公司对标（太阳能/储能）**：

| 公司 | 年营收 | 员工 | 人均产值 | 毛利率 | 净利率 |
|------|--------|------|---------|--------|--------|
| Enphase Energy (ENPH) | $1.38B | ~3,000 | $460K | 45% | 22% |
| SolarEdge (SEDG) | $900M | ~5,000 | $180K | 25% | -15% |
| Goal Zero (owned by NRG) | ~$150M | ~300 | $500K | 40% | ~10% |
| EcoFlow (private) | ~$800M | ~3,500 | $229K | ~35% | ~8% |
| Jackery (SZ:300820) | ~$500M | ~2,000 | $250K | 30% | 8% |

> 注：以上数据来自公开财报或行业估算，仅供对标参考。每次调查时应搜索最新数据更新。

#### 2. 毛利率估算

**按产品线基准**：

| 产品类型 | 毛利率范围 | 典型值 | 说明 |
|---------|----------|--------|------|
| 太阳能面板（自有品牌） | 15-30% | 22% | 竞争激烈，同质化高 |
| 储能电池（LiFePO4） | 20-40% | 30% | 有技术壁垒，品牌溢价 |
| 逆变器/控制器 | 30-50% | 38% | 技术含量高，专利保护 |
| 系统套装/Bundle | 35-55% | 42% | 组合定价，整体溢价 |
| 配件/线缆/连接器 | 50-75% | 60% | 高毛利，搭售逻辑 |
| 便携电源站 | 25-40% | 32% | 竞争加剧，品牌溢价存在 |
| App/SaaS 订阅 | 80-95% | 90% | 边际成本近零 |

**加权平均毛利率计算**：
```
公司毛利率 ≈ Σ (产品线营收占比 × 产品线毛利率)
```

#### 3. 净利率估算

```
净利率 ≈ 毛利率 - 运营费用率

运营费用率构成（DTC品牌典型值）：
- 营销/广告: 15-25%（Amazon PPC + Facebook + Google）
- 人力成本: 8-15%
- 仓储物流: 5-10%
- 研发: 3-8%
- 管理/行政: 3-5%
- 其他: 2-3%
```

**快速估算法**：
| 公司类型 | 毛利率 | 运营费用率 | 净利率 |
|---------|--------|----------|--------|
| 高增长DTC品牌（烧钱阶段） | 30-40% | 35-45% | -5% ~ 5% |
| 成熟DTC品牌（盈利阶段） | 30-40% | 22-30% | 8-15% |

## 三、差评痛点结构化分析

> 差评不是噪音，是客户用脚投票的真相。

### 采集来源（按优先级）
1. **Trustpilot** — DTC品牌最重要的评价平台
2. **Amazon Reviews** — 1-2星评价，按"最新"排序
3. **BBB Complaints** — 正式投诉，公司有义务回应
4. **Reddit** — `site:reddit.com "[品牌名]" problem OR issue OR complaint`
5. **Google Reviews** — 如有实体店/仓库
6. **专业论坛** — 行业垂直社区（如 diysolarforum.com）

### 分类框架

对所有差评/投诉按以下维度分类：

| 类别 | 代码 | 示例 | 严重度 |
|------|------|------|--------|
| **产品缺陷** | PD | 电池不充电、面板功率不达标 | 🔴 高 |
| **安全问题** | SF | 过热、爆炸、短路 | 🔴🔴 极高 |
| **售后服务** | CS | 不回复、推诿、处理慢 | 🔴 高 |
| **退货/退款** | RT | 退货困难、手续费、不退款 | 🟡 中 |
| **物流/履约** | SH | 延迟、损坏、错发 | 🟡 中 |
| **说明/兼容** | DC | 说明不清、配件不兼容 | 🟡 中 |
| **定价/性价比** | PR | 觉得不值、隐性收费 | 🟢 低 |
| **保修/质保** | WR | 保修范围争议、过保不修 | 🟡 中 |

### 分析维度

对每个类别评估：

```markdown
### 差评痛点矩阵

| 类别 | 提及频率 | 占比 | 持续时间 | 是否结构性 | 公司回应 | 你的机会 |
|------|---------|------|---------|-----------|---------|---------|
| 售后服务(CS) | 高 | 35% | 12月+ | ✅ 是 | 模板回复 | 提供人工客服方案 |
| 产品缺陷(PD) | 中 | 20% | 6月+ | ⚠️ 部分 | 换货 | 加强QC |
| 退货退款(RT) | 中 | 18% | 6月+ | ✅ 是 | 坚持政策 | 更灵活退换政策 |
```

### 判断标准

- **结构性弱点**（持续 > 3个月 + 公司无有效改善）：
  - 需要新增团队/系统才能解决
  - 公司回应为模板式或推诿式
  - 多平台交叉验证同一问题
  → **你的长期差异化机会**

- **偶发性问题**（< 3个月 or 单一事件）：
  - 物流延迟、季节性断货、个别批次问题
  - 公司有积极改善行动
  → **不构成切入机会**

### 差评趋势分析

```
时间线：过去12个月差评主题变化
- Q1: [主要投诉主题]
- Q2: [主要投诉主题]  ← 是否有新问题出现？
- Q3: [主要投诉主题]  ← 老问题是否改善？
- Q4: [主要投诉主题]  ← 趋势是恶化还是改善？

趋势判断：恶化 / 稳定 / 改善
```

## 四、DTC vs 批发 定价分析

> 一家同时做零售和批发的公司，如何给分销商利润空间？

### 定价策略识别

| 策略 | 信号 | 对分销商意味着 |
|------|------|--------------|
| **MAP 政策** | 官网价 = Amazon价 = 第三方卖家价 | 有价格保护，分销商利润有保障 |
| **DTC优先** | 官网价 < Amazon价 | 不鼓励分销，利润空间压缩 |
| **渠道友好** | 有明确的 Dealer/Distributor 页面 | 欢迎分销，有批发价体系 |
| **B2B 分离** | 有独立的 B2B 网站或 OEM 页面 | 专业批发团队，价格体系清晰 |
| **Amazon占主导** | 90%+ 流量来自 Amazon | 分销价可能很紧，Amazon定价权高 |

### 采集清单
- [ ] **Dealer/Partner 页面** — 搜索官网 "dealers" "distributors" "partners" "wholesale" "B2B"
- [ ] **MAP 验证** — 对比官网、Amazon、第三方卖家价格是否一致
- [ ] **批量折扣** — 是否有 "request a quote" 功能
- [ ] **OEM/ODM** — 是否提供白标/贴牌服务
- [ ] **渠道冲突** — Amazon 是品牌自营还是有授权卖家？多少个卖家在卖？

## 五、Amazon 成本拆解（FBA/FBM 利润精算）

> 参考卖家精灵（SellerSprite）利润计算器逻辑，精确还原 Amazon 卖家的全成本结构。
> 核心公式：**净利润 = 售价 - 产品成本 - 头程运费 - Amazon扣费 - 营销成本 - 售后成本 - 其他成本**

### 卖家精灵利润计算器输入项

| 输入字段 | 说明 | 默认/基准值 |
|---------|------|-----------|
| 售价 (Listing Price) | Amazon 上的销售价格 | 来自产品页面 |
| 产品成本 (Unit Cost) | FOB 出厂价 | 来自 1688/ImportYeti |
| 头程运费 (Shipping to Amazon) | 中国→美国仓库的运费 | 海运: $0.5-2/kg; 空运: $5-10/kg |
| FBA费用 | 亚马逊配送费（自动按尺寸重量计算） | 见下表 |
| 佣金 (Referral Fee) | 品类佣金 | 8-15%（见下表） |
| 广告费 (PPC) | 占售价比例 | 10-20%（竞争品类更高） |
| 退货损失 (Returns) | 退货率 × 处理成本 | 3-15%（品类差异大） |
| 仓储费 (Storage) | 月均存储成本 | $0.56-2.40/立方英尺 |

## 六、美国 Dealer 分销体系详解

> 理解美国的分销渠道架构，是判断品牌定价策略和合作空间的关键。

### 6.2 角色定义

| 角色 | 定义 | 典型加价率 | 职能 |
|------|------|----------|------|
| **Master Distributor** (总分销商) | 从品牌方买入大批量，分销给区域商/Dealer。通常有排他区域权 | 获得 MSRP 的 **40-50%** 折扣（即以 50-60% MSRP 买入） | 仓储、信用风险承担、区域覆盖、培训 |
| **Regional Distributor** (区域分销商) | 覆盖特定区域，从总分销商或品牌方买入 | 获得 MSRP 的 **30-40%** 折扣（即以 60-70% MSRP 买入） | 区域配送、本地关系维护、库存 |
| **Dealer** (经销商) | 直接面向终端用户/安装商，通常需要品牌授权 | 获得 MSRP 的 **20-35%** 折扣（即以 65-80% MSRP 买入） | 销售、安装支持、终端服务 |
| **Retailer** (零售商) | 面向消费者的店面/线上商城（Home Depot/Costco等） | 获得 MSRP 的 **30-45%** 折扣（即以 55-70% MSRP 买入） | 客流量、品牌展示、消费者触达 |
| **Installer/Contractor** (安装商) | 太阳能系统安装商，B2B采购+安装服务 | 以 Dealer 价采购，收取 **安装服务费** 30-50% 加成 | 安装、设计、许可证办理 |

Dealer 卖给终端          ~$170-190     ~5-15% off   Dealer毛利: 25-35%

### 6.4 MAP (Minimum Advertised Price) 政策详解

| 概念 | 说明 |
|------|------|
| **MAP 定义** | 品牌方设定的**最低广告价格**，所有授权经销商不得以低于此价格公开宣传/广告 |
| **MAP ≠ 最低售价** | MAP 只限制广告价格，不限制实际成交价（"add to cart for price"策略合法） |
| **法律基础** | 美国反垄断法允许 MAP（单方面定价政策），但禁止价格固定协议 |
| **执行方式** | 违反者 → 警告 → 暂停供货 → 取消授权资格 |
| **典型MAP水平** | MSRP 的 **85-95%**（即允许公开折扣 5-15%） |
| **MAP保护价值** | 防止价格战 → 保护 Dealer 利润 → Dealer 愿意做推广/库存 → 品牌覆盖面扩大 |

**MAP 合规示例**：
```
MSRP = $199
MAP = $179 (90% of MSRP)

✅ 合规: Amazon 标价 $193, 官网 $199, Dealer广告 $185
❌ 违规: 某Dealer在网上广告 $159 → 品牌方警告/断货
⚠️ 灰色: Amazon Lightning Deal $149 → 短期促销通常默许
```

### 6.5 Dealer Program 分级体系

| 级别 | 名称 | 典型折扣 | 最低采购量 | 要求 |
|------|------|---------|----------|------|
| **T1** | Authorized Dealer (授权经销商) | MSRP × **70-80%** | $2K-$10K/年 | 基础申请，品牌审核 |
| **T2** | Preferred Dealer (优选经销商) | MSRP × **60-70%** | $10K-$50K/年 | 销量目标，展示要求 |
| **T3** | Master Distributor (总分销商) | MSRP × **50-60%** | $50K-$500K/年 | 仓储能力，区域排他，团队要求 |
| **T4** | OEM/White Label (贴牌) | 到岸成本 × **110-130%** | $100K+/年 | 定制产品，最低起订量 |
| **特殊** | National Account (全国大客户) | 直接谈判 | $500K+/年 | Home Depot/Costco 等 |

### 6.6 渠道冲突与平衡策略

| 冲突类型 | 描述 | 品牌常见应对 |
|---------|------|------------|
| **DTC vs Dealer** | 品牌官网价格低于经销商 → Dealer不满 | MAP政策保价；官网价≥MAP；给Dealer独家SKU |
| **Amazon vs 线下** | Amazon价格透明，消费者线下看货线上买 | Amazon价格=MAP；线下Dealer提供安装服务溢价 |
| **Dealer互杀** | 同区域多个Dealer价格竞争 | 区域保护政策（一定范围内限制授权数量） |
| **大零售商压价** | Home Depot/Costco压低采购价，其他渠道无法竞争 | 给大零售商独家SKU/规格，与Dealer产品线差异化 |

### 6.7 太阳能行业特有分销结构

| 特点 | 说明 |
|------|------|
| **Stocking Distributor** | 有自己仓库的分销商（如 CED Greentech, BayWa r.e., Soligent），承担库存风险 |
| **Drop-ship Dealer** | 不持有库存的经销商，订单直接由品牌方/分销商发货 |
| **Value-Added Reseller (VAR)** | 提供系统设计+安装的增值经销商，利润来自服务而非产品差价 |
| **Buying Group** | 多个小型安装商/Dealer联合采购获取更好价格（如 NABCEP 认证安装商） |
| **两步 vs 一步分销** | 两步: 品牌→分销商→Dealer；一步: 品牌→Dealer直供 |

### 6.8 行业标准折扣与加价率总结

| 渠道层级 | 买入折扣 (off MSRP) | 毛利率 | 典型净利率 |
|---------|---------------------|--------|----------|
| 品牌DTC (Amazon/官网) | — | 50-75% | 8-20% |
| 品牌→总分销商 | **40-50% off** | 品牌毛利 50-65% | — |
| 总分销商→经销商 | **30-40% off** | 分销商毛利 15-25% | 5-8% |
| 经销商→终端 | **20-30% off** | 经销商毛利 25-40% | 8-15% |
| 品牌→大零售商 | **35-50% off** | 零售商毛利 35-50% | 3-8% |
| 安装商（含安装） | **30-40% off 产品** | 安装毛利 45-65% | 15-25% |

> **关键洞察**:
> - **Keystone Pricing**（2倍加价）在电子产品中已过时，实际倍率通常 1.4-1.8x
> - 太阳能面板利润薄（分销商毛利15-20%），但储能/逆变器/系统方案利润高（25-40%）
> - DTC品牌给经销商的空间取决于自身毛利率：毛利率>40%的品牌才有余地建分销网络

### 分销商合作吸引力评分

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 品牌知名度 | 15% | Amazon BSR/评价数/品牌搜索量 |
| 产品毛利空间 | 25% | 高毛利产品占比，分销商利润空间 |
| 渠道政策友好度 | 20% | MAP政策/Dealer体系/B2B支持 |
| 产品创新力 | 15% | 新品频率/专利数量/差异化 |
| 售后支持 | 10% | 对分销商的技术支持/培训 |
| 市场增长 | 15% | 品类增速/公司增速 |

### 利润空间估算

```
分销商潜在利润 = 终端零售价 × (1 - 分销折扣率) - 分销商成本

典型折扣率：
- DTC品牌给分销商: 30-40% off MSRP
- 传统品牌给分销商: 40-50% off MSRP
- OEM/白标: 成本 + 10-20% 加成

如果品牌方自己的毛利率只有 20-25%（如太阳能面板），
→ 分销商折扣空间极小（5-15%）
→ 走量为主，利润薄

如果品牌方毛利率 35-50%（如储能电池、逆变器、套装）
→ 分销商折扣空间合理（25-35%）
→ 有利可图
```
