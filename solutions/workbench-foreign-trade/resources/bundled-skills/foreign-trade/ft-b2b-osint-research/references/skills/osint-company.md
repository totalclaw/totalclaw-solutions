# Skill: 海外 B2B 公司调查

> 由 `/osint` 命令自动加载
> 核心哲学：公司说的和做的之间的落差，就是你的机会所在。

## PIR 清单
1. **合法性**: 公司是否真实注册？是否正常经营？
2. **信用**: 是否有付款能力和意愿？有无纠纷记录？
3. **决策链**: 联系人是否有采购权？真实决策者是谁？
4. **脉弱**: 他们有什么痛点/弱点是我们的切入机会？

## 数据采集清单

### 第一层：基础核实（必做）
- [ ] **官网分析** — WebFetch 获取官网，检查产品一致性、联系方式真实性
- [ ] **域名 WHOIS** — `https://who.is/whois/[域名]`，记录注册时间、注册地
  - 🔴 红旗：域名注册 < 1年
- [ ] **LinkedIn 公司页** — 搜索记录员工数、成立时间
  - 🔴 红旗：声称大公司但员工 < 10人
- [ ] **Google 新闻** — 搜索 `"[公司名]" fraud OR scam OR lawsuit OR complaint`
- [ ] **评价平台** — Trustpilot (`trustpilot.com/review/[域名]`)、BBB、Google Reviews

### 第二层：信用核查（重要客户）
- [ ] **D&B** — `dnb.com` 基础信息
- [ ] **BBB**（美国）— `bbb.org`
- [ ] **Companies House**（英国）— `find-and-update.company-information.service.gov.uk`
- [ ] **行业展会记录** — 是否参加 Solar Power International、Intersolar 等

### 第三层：决策人情报（Sales Intel MCP）
- [ ] **域名邮箱搜索** — `hunter_domain_search([域名])`，获取全部可用邮箱、职位、LinkedIn
- [ ] **高管筛选** — `hunter_domain_search([域名], department="executive")`，定位管理层
- [ ] **销售团队** — `hunter_domain_search([域名], department="sales")`，定位采购/销售决策人
- [ ] **关键人物深度画像** — `apollo_person_enrich([姓名], [公司])`，获取履历、所在地、验证邮箱
- [ ] **邮箱格式** — 记录 Hunter 返回的 pattern（如 `{first}.{last}@域名`），用于推算其他联系人邮箱

> **⚠️ So What**: 每个分析模块输出后，必须追加 `<div class="so-what">` 块，
> 给出 1-2 句可执行的行动建议。禁止只列数据不给结论。

### 第四层：财务核查（上市公司 — SEC EDGAR MCP）
> 仅适用于美国上市公司。私营公司跳过此层。

- [ ] **CIK 查找** — 通过公司名或股票代码查找 SEC CIK 编号
- [ ] **10-K 年报** — 提取最新年度营收、净利润、资产负债关键指标
- [ ] **10-Q 季报** — 提取最近季度营收趋势、同比增长
- [ ] **8-K 重大事件** — 检查近6个月是否有重大事件披露
- [ ] **内幕交易** — Form 4 检查高管近期买卖行为
  - 🔴 红旗：高管集中抛售
  - ✅ 正面：高管增持

> **⚠️ So What**: 每个分析模块输出后，必须追加 `<div class="so-what">` 块，
> 给出 1-2 句可执行的行动建议。禁止只列数据不给结论。

### 第五层：供应链溯源（ImportYeti）
- [ ] **进口记录** — 搜索 `importyeti.com/company/[公司名]`
  - 进口商（美国公司名）
  - 出口商（中国工厂名）
  - 品类 / HS 编码
  - 进口频次和数量趋势
- [ ] **供应商反查** — 用中国工厂名反查：还给哪些品牌供货？
- [ ] **趋势判断** — 进口频次上升/稳定/下降？断货信号？

### 第六层：深度核查（大单 >$50K）
- [ ] **法律记录** — `courtlistener.com` 搜索公司名
- [ ] **企业关联** — 检查母子公司、法人关联、是否壳公司
- [ ] **招聘情报分析** — 加载 `skills/osint-hiring.md` 执行完整分析
  - 多平台汇总：LinkedIn + Indeed + Glassdoor + 公司ATS
  - ZoomInfo 部门分布 → 部门增长率计算
  - 岗位战略信号解读（Sourcing=换供应商 / QA=质量问题 / 新区域Sales=市场扩张）
  - 人效对标 → 你用AI需要几个人替代他们的团队
  - 市场机会倒推（他们花钱验证的方向 = 你跟进的方向）
- [ ] **技术栈** — `builtwith.com/[域名]` 或 web-check 分析
  - ERP/CRM 信号（NetSuite/Salesforce = 正规运营）
  - Shopify/WooCommerce = DTC 模式

### 第七层：产品盈利结构 & 财务健康度（DTC品牌/分销商必做）
> 加载 `skills/osint-profitability.md` + `skills/osint-pricing-anatomy.md` 执行完整分析

- [ ] **产品线分类** — 四象限法：🧲流量磁铁 / 🚀利润引擎 / 🛡️护城河 / 🐕鸡肋
  - Amazon 旗舰店按 BSR/价格/评价数/上架时间分类
  - 官网按价格带/标签/套装拆解
  - 新品清单（评价 < 50 + 上架 < 6个月）
  - 专利产品（USPTO 搜索）
- [ ] **人均产值** — 年营收 ÷ 员工数，对标行业基准
- [ ] **毛利率/净利率估算** — 产品线加权 + 行业基准交叉估算
- [ ] **差评痛点结构化** — Trustpilot/Amazon/BBB 差评分类(PD/SF/CS/RT/SH/DC/PR/WR)
  - 各类别占比、持续时间、是否结构性
  - 公司回应模式（积极/模板/推诿）
- [ ] **DTC vs 批发定价分析** — MAP政策/Dealer体系/价格一致性
- [ ] **对标公司财务** — 搜索同行业上市公司作为参照
- [ ] **价格瀑布分析** — FOB→到岸→DTC→分销→零售 全链路倍率计算
  - FOB→DTC倍率、FOB→零售倍率 → 对照倍率诊断矩阵（3x/5x/8x/10x）
  - 渠道定价策略（MAP政策/Dealer体系/渠道冲突检查）
  - 人均产值健康度（对照行业基准表）

### 第八层：中国出海品牌运营拆解（中国DTC品牌必做）

- [ ] **品牌进化阶段判断** — Stage 0-5（铺货→萌芽→渠道扩张→多品牌→生态→全球化）
  - 渠道数、SKU数、员工数、技术栈、App、子品牌、专利数
- [ ] **运营模式七维度拆解**
  - 供应链架构（自有工厂/OEM/ODM、中国端vs美国端）
  - 渠道策略（Amazon依赖度、DTC占比、线下进度、B2B/OEM）
  - 定价与产品策略（价格破坏/价值创新/品牌溢价/生态锁定）
  - 营销组合（PPC/KOL/SEO/社媒/PR/邮件）
  - 组织架构（双总部模型、中美员工比例、决策权分布）
  - 技术护城河（专利/自研芯片/App/IoT/数据飞轮）
  - 关税与地缘政治适应（东南亚转移/近岸/价格转嫁）
- [ ] **竞争定位** — 三维地图（技术壁垒×品牌溢价×份额）+ 中国DTC常见弱点
- [ ] **可复制性评估** — 哪些环节你能用AI精简复制
- [ ] **中国DTC专用脉弱** — 关税×产地、Amazon依赖×差评、SKU膨胀×评价分散等

## 信息一致性核查（Discrepancy Analysis）

> 公司说的和做的之间的落差，是最强的风险信号。

完成数据采集后，**必须**将公司自称信息与核实结果做系统性比对：

| 字段 | 公司自称 | 来源 | 核实结果 | 来源 | 差异 | 严重度 |
|------|---------|------|---------|------|------|--------|
| 员工规模 | [官网/LinkedIn自称] | 官网 | [LinkedIn实际/ZoomInfo] | LinkedIn | [倍数差异] | 高/中/低 |
| 成立时间 | [官网声称] | 官网 | [域名注册/工商记录] | WHOIS/注册局 | | |
| 营收规模 | [声称/暗示] | 官网/PR | [SEC/估算/D&B] | 财报/估算 | | |
| 总部地址 | [官网地址] | 官网 | [Google Street View/注册地] | 地图/注册局 | | |
| 主营业务 | [官网描述] | 官网 | [ImportYeti品类/实际产品] | 海关/平台 | | |
| 客户/案例 | [官网案例页] | 官网 | [可否独立验证] | 搜索 | | |

**严重度判定**：
- **高**：核心数据（营收/员工/成立时间）差异 > 3倍，或关键信息无法核实
- **中**：差异 1.5-3 倍，或部分信息来源单一
- **低**：差异 < 1.5 倍，可合理解释（如含外包/兼职）

**自动触发规则**：
- 任何 **高严重度** 差异 → 风险评级自动升至 黄色（至少）
- 3 个以上 **中严重度** 差异 → 风险评级自动升至 黄色
- 任何字段 **完全无法核实** → 标记为信息黑洞，在报告中高亮

## 五维风险评分（Risk Scorecard）

> 比单一红绿灯更有说服力的结构化评估。

完成信息一致性核查后，按以下五个维度各打 1-5 分：

| 维度 | 1 分（极低风险） | 3 分（中等风险） | 5 分（高风险） | 数据来源 |
|------|----------------|----------------|---------------|---------|
| **诚信度** (Integrity) | 多源信息完全一致，无差异 | 有 1-2 处差异但可解释 | 核心信息矛盾或无法核实 | 信息一致性核查表 |
| **法律风险** (Legal) | 无诉讼/制裁/负面记录 | 有小额纠纷但已解决 | 重大诉讼/执行/制裁命中 | CourtListener + sanctions_check + BBB |
| **财务压力** (Financial) | 财务稳健，进口持续 | 营收波动或信息有限 | 严重亏损/破产/进口归零 | SEC + payment_risk_score + ImportYeti |
| **声誉** (Reputation) | Trustpilot 4+, 正面评价主导 | 3-4 分，差评有但不集中 | <3 分或差评持续 > 3 月同一主题 | Trustpilot + G2 + BBB + Amazon |
| **稳定性** (Stability) | 域名 5+ 年，团队稳定 | 域名 2-5 年，有人员流动 | 域名 < 1 年 / 高管连续离职 / 频繁变更 | WHOIS + LinkedIn + 招聘动态 |

**综合风险等级**：
```
总分 = 五个维度之和（5-25 分）

5-8 分   → 低风险（正常推进）
9-14 分  → 中风险（加强合同保护 + 补充核实）
15-25 分 → 高风险（暂缓合作 / 要求全额预付）
```

**报告输出格式**：
```
### 五维风险评分

| 维度 | 分数 | 关键依据 |
|------|------|---------|
| 诚信度 | X/5 | [一句话依据] |
| 法律风险 | X/5 | [一句话依据] |
| 财务压力 | X/5 | [一句话依据] |
| 声誉 | X/5 | [一句话依据] |
| 稳定性 | X/5 | [一句话依据] |
| **总分** | **XX/25** | **风险等级** |
```

## 脉弱交叉分析（核心）

> 单一数据点没有意义，**矛盾点**才有价值。

完成数据采集后，执行以下交叉分析：

| 组合 | 逻辑 | 信号 |
|------|------|------|
| 招聘 JD × 进口记录 | 招 Sourcing + 进口量下降 | 正在换供应商，切入窗口 |
| 差评主题 × 技术栈 | 差评持续 > 3月 + 无解决能力 | 结构性弱点，你的差异化机会 |
| 员工流动 × 评分趋势 | 关键岗位连续换人 + 评分下滑 | 内部动荡，客户信任流失 |
| 进口频次 × BSR/销量 | 无进口 + BSR 暴跌 | 断货危机，抢他的下游客户 |
| 域名年龄 × 员工数 × SKU 数 | 域名 < 1年 + < 5人 + 50+ SKU | 铺货型机会主义者，非真玩家 |
| Google Trends × 季节 | 搜索量即将上升 | 提前备货锁定合作的时机 |

## 客户规模分档 & 优先级评估

根据采集到的数据判断规模档位：

| 档位 | 年销售额 | 判断信号 | 打法建议 |
|------|---------|---------|---------|
| S0 | < $100万 | 域名新、员工少、SKU少 | 价格简单直接，小批量起 |
| S1 | $100万-$1000万 | 有稳定产品线，小团队 | 强调 ROI，提供数据支撑 |
| S2 | $1000万-$5000万 | 多渠道运营，开始建品牌 | 谈升级而非价格 |
| S3 | $5000万-$1亿 | 专业团队，多平台 | 流程对接，稳定供货优先 |
| S4 | $1亿-$10亿 | 专业采购体系 | 合规文件齐全，长期框架 |
| S5 | > $10亿 | 上市公司/全球化 | 多层关系，联合业务规划 |

### 账号优先级评分（Account Scoring）

> 规模只是一个维度。结合以下三维度打分，决定精力分配。

完成数据采集后，对目标做三维评分（各 1-5 分）：

| 维度 | 评估要点 | 数据来源 |
|------|---------|---------|
| **机会大小** | 年合同额潜力 + 产品线匹配度 | 规模档位 + 产品分析 |
| **赢单概率** | 是否在换供应商？竞品绑定深不深？ | 脉弱信号 + ImportYeti + 招聘JD |
| **战略价值** | 标杆效应？转介绍潜力？可扩品类/渠道？ | 公司类型 + 行业地位 + 渠道结构 |

```
总分 = 机会大小 × 赢单概率 × 战略价值（1-125 分）

Tier 1 (>60分): 全力攻坚 — 加载 sales-playbook 生成完整作战手册
Tier 2 (25-60分): 标准打法 — 模板化提案 + 标准触达节奏
Tier 3 (<25分): 轻量触达 — 自动化邮件 + 长线培育
```

## 红旗清单
🔴 立即标注高风险：
- 域名注册 < 6个月
- 无任何第三方独立提及
- 联系邮箱用 Gmail/Yahoo 等免费邮箱
- 要求首次合作全额预付
- LinkedIn 无真实员工或账号真实性存疑
- BBB 评分 D/F
- 高管集中抛售股票（SEC Form 4）
- 进口记录突然归零（可能运营困难）

🟡 需补充核实：
- 域名 6个月-2年
- 员工信息不完整
- 只有自建网站评价
- 联系人职位无法在 LinkedIn 核实
- 进口频次下降趋势

## 数据源合规约束

采集数据前检查：
- 绿色（自由使用）：工商注册系统、SEC EDGAR、Companies House、制裁名单、法院公开记录、OpenCorporates
- 黄色（谨慎使用）：LinkedIn 公司主页（不批量采集）、评价平台、Hunter.io（仅业务邮箱）
- 禁止：需登录才能访问的私有系统、来源不明的人员数据库、暗网数据

禁止采集：政府官员/军事人员信息、政治/主权/国家安全相关内容、个人私宅地址/私人手机。
