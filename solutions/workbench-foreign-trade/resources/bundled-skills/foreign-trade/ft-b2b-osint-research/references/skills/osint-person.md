# Skill: 海外决策人个人调查

> 由 `/osint` 命令自动加载
> 触发：目标为个人姓名或邮箱

## PIR 清单
1. **身份真实性**: 此人是否真实存在？是否真的在该公司任职？
2. **决策权**: 是否有采购决策权？还是只是执行者？
3. **背景核实**: 职业经历是否与声称一致？有无负面记录？

## 数据采集清单

### Buying Committee 识别（关键步骤）

> 不把客户当"一个人"，而是当"一张政治地图"。

当目标人物属于某个公司时，不仅调查此人，还要映射整个采购决策链：

- [ ] **角色分类** — 将目标人物和同公司其他联系人按以下角色分类：

| 角色 | 定义 | 典型职位 |
|------|------|---------|
| **经济决策人** (EB) | 最终签字批准预算 | CEO, VP Procurement, CFO |
| **技术把关人** (TG) | 评估方案技术可行性 | Engineering Manager, QA Lead |
| **实际使用者** (UB) | 日常使用产品的人 | Buyer, Category Manager, Ops |
| **内部教练** (CH) | 帮你在内部推动的人 | 任何支持者 |

- [ ] **每人四象限画像** — 对每个关键人物评估：
  - 目标 & KPI：被考核什么？（来源：招聘JD / LinkedIn / 年报）
  - 痛点 & 挑战：最头疼什么？（来源：差评分析 / 脉弱发现）
  - 顾虑 & 反对理由：可能拒绝的原因？（来源：竞品分析 / 行业经验）
  - 影响力 & 决策风格：数据驱动型还是关系型？（来源：LinkedIn / 社交媒体）

- [ ] **攻略路径设计** — 确定：最容易接触谁 → 通过谁了解内部政治 → 最终说服谁

### 邮箱调查（如有邮箱）
- [ ] **Maigret 邮箱搜索** — `maigret [邮箱]`，检查在哪些平台注册
  - 活跃账号越多 = 真实人物概率越高
- [ ] **邮箱域名核查** — 企业邮箱 vs 免费邮箱（企业邮箱更可信）

### 销售情报（Sales Intel MCP）
- [ ] **Hunter 邮箱查找** — `hunter_email_finder([域名], [名], [姓])`，精确查找此人企业邮箱
- [ ] **Hunter 邮箱验证** — `hunter_email_verifier([邮箱])`，验证邮箱是否可送达
- [ ] **Apollo 深度画像** — `apollo_person_enrich([名], [姓], [公司])`，获取：
  - 完整职业履历（前雇主、任职时间）
  - 当前所在城市和时区
  - 邮箱验证状态
  - 职级（seniority）和部门（department）
- [ ] **同公司决策链** — `hunter_domain_search([域名], department="executive")`，找到此人上级/同级

### 社交账号搜索

**Step 1 — Maigret 邮箱/用户名反查（快速，400+ 平台）**
- [ ] `maigret [用户名]` 或 `maigret [邮箱]` — 适合有邮箱时的快速扫描
- [ ] 重点看：哪些平台有注册记录、用户名的一致性

**Step 2 — Social Analyzer 深度扫描（1000+ 平台，置信度评分）**
- [ ] **快速精准扫描（推荐默认）**：
  `social_search_username(username="[用户名]", websites="twitter linkedin github instagram facebook youtube reddit", mode="fast", filter="good")`
- [ ] **广域扫描（全平台）**：
  `social_search_username(username="[用户名]", websites="all", top=100, filter="good maybe")`
- [ ] **多用户名变体扫描**（当用户名不确定时）：
  `social_search_multi_usernames(usernames="[name1] [name2] [name3]")`
- [ ] 关注 confidence ≥ 70% 的结果；`maybe` 状态需人工核验

**Step 3 — LinkedIn 详细调查**
- [ ] Playwright 搜索：工作经历、教育背景、人脉数量
  - 🔴 红旗：账号很新、连接 < 50、经历描述模糊

**Step 4 — Google 交叉验证**
- [ ] `"[姓名]" "[公司名]"` — 公司相关出现记录
- [ ] `"[姓名]" "[职位]"` — 行业演讲/文章/访谈
- [ ] `"[姓名]" fraud OR complaint` — 负面记录

## 数字足迹结构化审查（Digital Footprint Audit）

> 扫描结果不是列一堆链接，而是分类评估，形成可行动的画像。

完成 Maigret + Social Analyzer 扫描后，将所有发现按以下四个维度分类：

### 职业存在（Professional Presence）

| 平台 | 状态 | 活跃度 | 关键发现 |
|------|------|--------|---------|
| LinkedIn | 找到/未找到 | 高/中/低/无 | [连接数、经历完整度、背书数] |
| GitHub | | | [项目、贡献频率、技术栈] |
| 行业论坛/社区 | | | [发帖、回答、声誉积分] |
| 公开演讲/文章 | | | [会议、博客、播客] |
| 专利/学术 | | | [USPTO、Google Scholar] |

**评估**：职业存在丰富度（1-5）— 越丰富 = 此人越真实、越专业

### 商业存在（Commercial Presence）

| 平台 | 状态 | 关键发现 |
|------|------|---------|
| Amazon Seller | | [店铺、品牌、评价] |
| Alibaba/1688 | | [供应商身份？] |
| Shopify/独立站 | | [其他商业项目] |
| Crunchbase/AngelList | | [创业/投资记录] |

**评估**：是否有其他商业利益可能影响采购决策？

### 社交活跃度（Social Activity）

| 平台 | 状态 | 活跃度 | 内容倾向 |
|------|------|--------|---------|
| Twitter/X | | | [行业讨论/个人/混合] |
| Instagram | | | [职业/个人/品牌] |
| YouTube | | | [行业内容？] |
| Reddit | | | [参与哪些 subreddit？] |
| Facebook | | | [公开信息] |

**评估**：社交信号强度（1-5）— 与自称职位/身份是否一致

### 风险信号扫描（Risk Signals）

扫描中发现以下任何情况，标记为风险信号：

- [ ] **身份矛盾**：不同平台上姓名/职位/公司不一致
- [ ] **时间线断裂**：职业经历有无法解释的空档期
- [ ] **真实性存疑信号**：AI 生成头像、模板化个人简介、批量注册痕迹
- [ ] **争议内容**：公开的极端言论、歧视性内容、诽谤投诉
- [ ] **关联风险**：与已知高风险/争议实体有公开关联

**隐私边界**：疑似私人账号（交友、健康等）不纳入报告，不分析。仅记录「存在私人账号，未采集」。

### 数字足迹综合评估

```
可信度评分 = 职业存在 × 0.4 + 商业存在 × 0.2 + 社交活跃度 × 0.2 + 风险信号（扣分）× 0.2

高可信（4-5）：多平台一致，职业存在丰富，无风险信号
中可信（2.5-3.9）：部分平台有记录，信息基本一致
低可信（<2.5）：极少数字存在，或存在矛盾/风险信号
```

## 红旗清单
🔴 高风险：
- LinkedIn 账号真实性存疑（AI 生成图片、模糊经历）
- 邮箱在所有平台无注册记录（身份真实性存疑）
- 多平台个人信息相互矛盾
- 无任何公司活动出现记录

🟡 黄色信号：
- 社交媒体存在但极低活跃度
- 只有 LinkedIn，无其他任何数字足迹

## ACH 假设框架（个人）
```
假设 A: 真实员工，有采购决策权
假设 B: 真实员工，只是执行者（需要找上级）
假设 C: 身份真实性存疑或冒用他人身份（高风险）
```

## 个人数据采集边界（必须遵守）

可采集（公开商业信息）：
- 职位、公司、LinkedIn 公开资料、公开演讲/文章
- 企业邮箱（Hunter.io）、公开联系方式
- 职业经历、教育背景、行业活动记录

禁止采集：
- 个人私宅地址、私人手机号
- 家庭成员信息、个人财务记录
- 政府官员、军事人员的任何个人信息
- 敏感属性：健康、种族、宗教、政治观点

social-analyzer / maigret 扫描结果中，如发现疑似私人账号（交友、健康等），不纳入报告，不分析。
