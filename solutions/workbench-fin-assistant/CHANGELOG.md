# 智能金融助手 CHANGELOG

## 1.1.0 (2026-11-03)

- 新页签「AI 网关」（统一 AI 网关）：所有模块的模型调用都过网关。多模型智能路由（按场景 / 数据级别 / 问题复杂度命中规则，依次尝试、失败自动换下一个；客户敏感数据只落内网模型）；脱敏与安全围栏（发往非内网模型前把身份证、银行卡、手机号、邮箱、登记的客户名换成占位符，回答再还原；越权指令拦截；输出禁语标记、编造的证件号打码）；全量审计日志（每次调用的路由、依次尝试的模型、脱敏计数、围栏命中、耗时、请求与结果指纹，串联哈希，可筛选、导出 CSV）。带「试一下」：看一段话会被路由到哪、脱成什么样。
- 新页签「资料智能处理」：WPS（.wps/.et/.dps，含老格式）、Word、PDF、Excel、PPT、图片、音频、视频；按文件头认格式；图片本机 OCR，音频 / 视频经 ffmpeg 取声音后本机语音模型转写（资料不出本机）；先关键词分类、拿不准再交模型在固定类目里选；按类目抽关键字段并逐字核对原文摘录；可入金融知识库、导出资料台账。附 6 份示例资料。
- 新页签「智能体编排」：可视化工作流（开始 / 大模型 / 知识检索 / 条件分支 / 变量赋值 / 插件 / 回复，拖动、连线），调试运行看每个节点的输入输出；多租户隔离（每个租户独立的智能体、运行记录、插件、API 密钥）；插件是声明式清单（HTTP 请求或调本工作台的制度问答 / 智能问数 / 知识库检索），不执行上传的代码；发布后经本机 API（127.0.0.1，租户密钥）调用。自带两个示例智能体。
- 新页签「AI 项目管理」：全生命周期（立项→运维）进度与规则化风险预警；日报周报从 git 提交、任务流转、会议纪要汇总，数字由程序统计、模型只写文字，对不上打回重写；企业微信 / 钉钉 / 飞书群机器人定时推送；Jira / TAPD / 禅道 / ONES 接口接入，其它系统导出表格导入；需求管理 AI 化（生成需求文档、程序预检含糊词 / 缺验收标准 + AI 评审、按瀑布 / 敏捷 / DevOps 拆任务并导出）。附示例项目。
- 智能问数：新增多数据源（表格 / App 数据库只读 SQL / HTTP 接口 / 浏览器抓包 HAR 零侵入接口捕获，字段自动对列）与报表、API、任务三种取数形态（报表按口径重算不调模型；GET /v1/reports/<id>；定时重算并推送）。
- 智能检索：简单问题亚秒直答（与已确认的常见问题足够像就直接给答案，不检索、不调模型；引用的制度换版即停止直答；点赞自动收录、点踩撤下）；复杂问题多步检索（拆成子问题分别检索后合并证据）。
- 新页签与子模块按需懒加载：第一次点开才加载对应代码。
- 安全：智能体（含本机 API 调用）的输入先过网关输入围栏；本机 API 的报表接口只给本机构（第一个）租户的密钥读，报表上配了 apiTenants 的按它；上次开着的本机 API 在 App 重启后自动再开；HTTP 插件地址的主机部分不能用占位符、不能指向本机 / 链路本地地址、不跟随跳转，请求头的值存系统钥匙串（plugins.json 只留头名），清单没写 `"internal": true` 的插件输入先按网关规则脱敏；导入的 HAR 落盘前去掉 cookie、请求头、查询串和请求体；「设置」里取消内网模型时网关默认模型的内网标记一起取消；只依据知识库资料（没有制度条款）的常见问题 90 天后停止直答，需重新确认。

## 1.0.3 (2026-11-03)

- 知识库命中的数据级别：文档自己的级别与来源级别取更严的那个（自动创建的文档库来源默认「公开」，日常由每份文档的级别决定）；敏感级按条剔除。

## 1.0.2 (2026-11-03)

- 新页签「金融知识库」：知识来源可选本地或远程、可多选，每个来源单独设数据级别（公开 / 内部 / 客户敏感）——本方案文档库（导入产品手册 / 监管文件 / 培训材料，段落切块 + BM25）、App 本机知识库（选图谱，向量 + 关键词混合检索）、远程只读数据库（App 已配数据源 + SELECT 模板，{{q}} 按值转义代入，走只读 /v1/db/query：只读守卫 / 子账号授权 / 脱敏 / 数据访问审计）、远程检索接口（POST 地址 + 令牌钥匙串加密 + 字段映射，8 秒超时、≤2MB）。
- 检索测试：各来源单独限时并行，出错只影响自己；按来源轮流合并去重；审计记来源与问题指纹、不存原文。
- 制度问答（含手机端）可引用知识库作补充依据：制度条款优先，知识库出处单独标注，数字回原文核对包含知识库原文；客户敏感级来源只有确认内网模型时才检索进来（否则剔除并说明），用到时按敏感级路由模型。

## 1.0.1 (2026-11-03)

- 「安全与审计」挪到最后一个页签，改名「设置」（数据分级与模型路由、审计记录、明确不做的事都在里面）；打开默认进「制度与合规问答」。
- 制度问答加第④步「手机端提问」：本机局域网开一个对话页（扫码打开，地址带口令，可换口令），问题走同一条判定链、回答带出处，审计记来源（手机 / 电脑）；历史问答标来源。需要 App 提供局域网服务（lanServer）。
- 界面改中国金融风格：藏青 / 深蓝为主、金色细线点缀、红色表示增长，无衬线字体、规整克制；横幅背景加 K 线、上升箭头与 ¥ 水印。
