# 智能金融助手（workbench-fin-assistant）

当前版本 1.1.0。给银行、消费金融、保险机构用的业务 AI 工作台，依据《金融行业 AI 应用解决方案 2.0》，不含研发 Agent（编码助手、代码评审）。

原则：模型只负责理解、归纳和起草；取数、计算、核对、拦截、审批和留痕由程序完成。客户敏感数据只交给内网私有部署的模型，所有模型调用都有审计记录。

## 页签

| 页签 | 能做什么 |
|---|---|
| 制度与合规问答 | 导入本机构制度，员工提问后按条款原文作答并标出处和生效日期，数字回原文核对；禁区话题和依据不足直接拒答，拒答问题汇总给制度管理部门。和已确认的常见问题足够像的问题秒回，引用的制度换版后自动停止秒回；复杂问题自动拆开分别查。支持手机扫码提问。 |
| 金融知识库 | 接入产品手册、监管文件、培训材料等知识来源（本地文档、App 知识库、只读数据库、内网检索接口），每个来源单独设数据级别；维护常见问题，回答好的问答点赞即自动收录。 |
| 智能问数 | 用口语问经营数据，模型只负责理解问的是哪个指标，数字由程序按口径库计算，附口径说明和等价查询语句。数据可来自表格、只读数据库、内部接口，或在浏览器里导出的抓包文件（业务系统不用改）。问过的问题可存成报表，之后定时重算、推送到工作群，或由其它系统经本机接口取数。 |
| 资料智能处理 | 一次导入 WPS、Word、PDF、Excel、PPT、图片、录音、视频等资料，自动识别格式、取出文字（图片识字和语音转写都在本机完成）、分类、抽取关键字段，每个字段都核对原文；处理好的资料可进知识库，或导出资料台账。 |
| 智能体编排 | 拖拽搭建智能体流程（检索知识、调用模型、条件判断、调用插件、回复），调试时能看到每一步的输入输出；按租户隔离智能体、插件和密钥；发布后本机其它程序可凭密钥调用。自带两个示例智能体。 |
| AI 项目管理 | 跟踪项目从立项到运维的进度，按规则提示逾期、阻塞、进度落后等风险；根据代码提交、任务流转和会议纪要自动写日报周报（数字由程序统计），定时推送到企业微信 / 钉钉 / 飞书群；接 Jira、TAPD、禅道、ONES 或导入任务表；帮忙写需求文档、评审需求、按瀑布 / 敏捷 / DevOps 拆任务。 |
| 授信材料预审 | 检查材料是否齐全，抽取关键财务数据并定位到原文，程序校验报表平衡、比率、流水与收入匹配、证照有效期、大额与关联交易；起草预审意见（不下批准 / 拒绝结论），审批人逐条确认，修改留痕。 |
| 营销物料审查 | 按规则库查禁用表述、缺失的风险提示和不规范的收益表述，并做语义判断；逐条处理后导出预审意见，交合规岗终审。 |
| AI 网关 | 统一管理用到的模型：按场景、数据级别、问题难度自动选模型，失败自动换一个；发往外部模型前把身份证号、银行卡号、手机号、邮箱和登记的客户名换成占位符，回答再还原；拦截越权指令，标出违规用语；每次调用都有审计日志，可筛选、导出。可以先「试一下」，看一段话会被怎么处理。 |
| 后台与其他 | 直达对账、发票、流程时效、合同审查等已有工作台。 |
| 设置 | 确认模型是否内网私有部署、查看审计记录（串联哈希，删改可发现）、明确不做的事。 |

横幅右侧「一键载入演示数据」：各页签都填好示例内容（全部虚构），载入过程不调用模型。

## 使用须知

- 授信材料预审、智能问数处理的是客户敏感数据，要先由管理员确认并标记内网私有部署的模型。一键演示会把系统默认模型标成内网模型，只为演示，正式使用前需重新核实。
- 录音、视频的转写需要应用提供本机语音转写能力；旧版应用会提示升级，其它格式的资料不受影响。

## 规则与口径（`resources/`）

- `forbidden-topics.json` 禁区话题（合规部门维护）
- `marketing-rules.json` 营销物料规则库（合规与法务部门维护）
- `credit-checklists.json` 授信材料清单（授信管理部门维护）
- `metrics.json` 问数口径库（数据岗维护；示例主题域：零售存款）
- `demo/` 示例材料（虚构）

## 数据

全部保存在本机账号私有目录 `fin-assistant/` 下；接口令牌、群机器人地址用系统钥匙串加密保存，智能体密钥只存哈希。

工程说明见应用仓库 `docs/fin-assistant-workbench.md`；单测 `test/fin-assistant.test.mjs`。
