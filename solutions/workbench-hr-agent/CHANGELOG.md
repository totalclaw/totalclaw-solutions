# 人事部 · 招聘 CHANGELOG

## 1.0.0 (2026-10-22)

- 首版：JD 生成与歧视性用词体检、简历批量导入与结构化、三层筛选、面试题与评分卡、邀约草稿与确认后发送（宿主 caseMailSender）、offer 与入职清单、候选人看板。
- 证据核对：门禁与打分的证据必须是简历原话；简历未提及只判「未知」；总分与决定由程序计算；筛选表导出 CSV。
- 长时间操作期间向宿主报进度（workbenchActivity），运营中心大屏可在对应部门节点下看到。
- 批量解析 / 筛选走集群分身（HR2）：本机是主控且有在线员工机时，每份简历的模型调用在本机与各员工机之间轮流分，员工机失败的那份回本机重做；可关。
- 向量预筛（HR3）：按简历与岗位要求的文字相似度只保留前 80% / 60% / 40%，被筛掉的不调模型、标明原因、可手动改回。
- 第 8 步绩效评估（HR8）：AI 起草考核目标（权重归一到 100）、按自评 / 上级评价给建议分（证据须是原话，否则作废）、上级逐项改分、程序算总分与等级（A ≥90 / B ≥75 / C ≥60 / D）、导出考核表。
