# 网站测试 · 自动点测出报告

- id：`website-test`
- 分类：研发测试
- 类型：pipeline（runner `agent-pipeline`）

给一个网址，一个 AI 测试工程师用浏览器工具真实逐页点测：站点勘探 → 链接与资源体检 → 交互点测 → 表单与关键流程 → UI/响应式/可访问性，最后汇总成一份完整测试报告（问题按严重度分组、含证据/复现步骤/修复建议）。点「启动」即跳工作流页，6 个阶段逐节点真跑、逐个点亮。危险操作（支付/删除/真实注册）只验证不最终确认。

## 安装

```bash
npm run tcsol -- install website-test
```

运行记录保存在账号目录 `solution-runs.json`（按方案 id 分组），升级不影响。
