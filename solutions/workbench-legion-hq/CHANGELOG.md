## 1.0.0 (2026-10-22)

- 首版。8 个部门（`legion-*`）以方案包装在任意机器上，一台机器可承载多个；主控经集群通道 `config.set` 把部门装到员工机、`config.get` / `status.report` 回读装机与负载。
- AI 总经理判定（模型要 JSON，逐条校验，失败 / 通道错误回落关键词规则）→ 计划（命中部门常用工作流则展开）→ 按负载派 `worker.run` 并发执行 → 跨部门交接带上游产物 → 汇总 → 钱 / 签约 / 对外发布 / 录用 / 重大事项进老板待办，可批准或带意见驳回重做。
- 指挥大屏：点「启动 Web」在局域网起服务（默认 8240，被占顺延，访问口令），`/` 大屏、`/remote` 手机遥控、SSE 实时推送、断线重连；可在选定显示器全屏打开。
- 公司档案：默认北京泰途科技有限公司（标志用 App logo），可改；演示模式隐藏真实名称、例行事务 9 条、导演台（4 个内置剧本、暂停 / 重置、录制回放）、公司能力地图（39 项，按代码估计）。
- 子机打开本方案：显示本机承载的部门与主控派来的正在执行的任务。
- 同日补充：机器列表只算员工机；接收员工机回传的执行阶段（宿主 task.progress）并显示员工机 status.report 里的部门任务；
  勾选承载后员工机真正安装部门方案包（L3，宿主 legion.install）；宿主工作流页的集群工作流运行进大屏动态（E1）；按部门输出上限，剧本可用 legionConfig 按部门指定模型与输出上限（D7）；现场新建部门（L11：一句话 AI 起草，只能用已装部门的角色，人确认后保存，可分配到机器、按关键词派活）；大屏动画节点池修复：复用时清掉旧属性（旧的发光滤镜会带到下一次）、突发后收缩，加速长跑实测 60 帧、堆与节点数不随任务数增长（S9）；
  大屏部门节点 / 军团营地显示工作台细步骤（LG7 / HR7：法务逐条审查、人事筛选 37/100，主控本机 + 员工机 status.report）；
  大屏 / 遥控地址二维码（自写编码器，与 npm qrcode 逐模块一致）、大屏「军团营地」视图（V 键）；
  演示公司资料包（虚构「示例科技」，开启后各部门可引用）；来信文件夹（.eml / .txt / .md 自动成为来信任务）与公司邮箱来信（宿主 IMAP 收件箱）；
  待拍板 / 例行办完的系统通知（可同时发到老板 IM，需宿主 imRunLink.pushToImOwner）；任务产出导出为带公司抬头的 Word；剧本调优表；成本看板（演示口径估算）；
  部门专用模型与 key（L12，派往员工机的步骤带本次专用凭据，需宿主 2026-10-22 起）；OPC 考卷 39 题（作答、按检查点打分、导出覆盖率报告，含缺口排序与已知缺口）；能力地图中法务 / 人事 / 投诉 5 项状态更新。
- 等员工机结果的上限跟步骤执行上限走（6 分钟 + 1 分钟余量），不再被宿主默认 5 分钟 RPC 超时提前判失败（宿主 cluster-transport 支持单次派发 timeoutMs）。
- 故障恢复：员工机执行中掉线导致没办成的事，可「重办没办成的部分」——已交上来的部门成果保留，只把失败与「上游失败未执行」的步骤重新派出（执行中失败仍不自动重跑，由人确认机器恢复后再点）；大屏动态显示「老板让 #N 重办没办成的 K 步」。
