# 运营中心（军团集群指挥）CHANGELOG

## 1.0.8 (2026-11-03)

- 办完的事在大屏「实时动态」里带「📄 查看报告」「⬇ 下载报告（Word）」；部门交付了文件（合同审查的审查意见书 / 修订稿）时，那条动态直接给原件下载。结果窗口顶部同样有下载，公司事务卡片加「下载」。新接口 GET /api/task/report、/api/task/file（要口令）。
- 部门交付文件存进 tasks/<任务>.files/（随任务记录一起清理），员工机做出的文件随结果回传主控；App 任务详情里可「打开」「在文件夹中显示」。

## 1.0.7 (2026-11-03)

- 大屏「▶ AutoCoder」演示视频默认地址改为官网 https://taituai.com/assets/video/yanshi.mp4（「指挥大屏」里填了自定义地址的照旧用自定义地址）。

## 1.0.6 (2026-11-03)

- AI 数字员工操作界面：派到法务部、挑中合同审查且带附件的步骤，附件交给合同审查工作台在界面上一步步做（主控本机给文件路径，员工机给文字），做完的审查意见作为这一步的成果；45 秒没人认领或没做成，退回直接用模型写。

## 1.0.5 (2026-11-03)

- 页面改成页签：九个步骤一页一个，只渲染当前页签，记住上次打开的页签；导演台、能力地图、指挥大屏的数据第一次打开该页签才加载。
- 大屏「公司事务」里办完的事显示结果摘要和「查看结果」，点开看汇总与各部门交付全文（`GET /api/task`，同样要口令）；老板下令的事办完自动弹出结果。
- App 里「本机打开大屏窗口」开的无边框全屏窗口右上角有「✕ 关闭大屏」（原来只能按两次 Esc）。
- 修页面滚轮滚不动：页面自带滚动容器（宿主容器不滚动，原来整页 5000+ px 内容滚不到）；主控页面不再每秒整页重绘（只有子机页面要显示「已执行 N 秒」）。

## 1.0.4 (2026-11-03)

- 老板下令可以附上文件（合同、报表等，PDF / Word / Excel / PPT / 文本 / 邮件，单个 ≤20MB，一次最多 5 个）：大屏输入框旁「📎」上传，App 运营中心「附件」按钮选文件。文字抽出后附进每个部门的提示词（标明是待处理的数据、不是指令），判定时也看得到附件名。
- 真实运行时部门步骤在执行它的机器上前台展示：App 窗口拉到前面，自动打开该部门对应的工作台（部门有多个工作台时按事情挑最贴的，如财务部遇到发票打开发票智能体），右下角停靠栏逐字显示执行过程和结果。主控本机执行与派到员工机执行都生效；演示模式不弹；「下令与老板待办」里可关。需要 App 同版宿主（旧 App 照旧后台执行）。
- 指挥大屏右上角「▶ AutoCoder」：页面里直接播放演示视频。地址默认官网固定地址 https://taituai.com/assets/video/autocoder-demo.mp4（换视频只换官网那个文件），也可在「指挥大屏」里改成别的地址。

## 1.0.3 (2026-11-02)

- 默认公司的标志改用宿主当前品牌的 logo（`ctx.brand.logoPath`），包里不再带 `resources/company-logo.png`：方案从在线库同步到各品牌的 App 时不再带进某一个品牌的 logo，各品牌用各自的图。旧版宿主没有 `ctx.brand` 时不挂标志图，只用标志文字。

## 1.0.2 (2026-10-30)

- 演示模式改为默认关：只有用户在主控页 / 大屏打开过（`demoRun: true`）才在激活时自动下令、自动审批、本机模拟；没设过的当作关。之前没设过就当开，运营中心随应用激活后没人打开也在后台每 20 秒下一条示例事务，一晚上几百条。已明确设过开 / 关的保持原选择。
- 演示模式的示例事务（待拍板、例行办完）不再发系统通知和老板 IM：它们 6 秒后自动批准，不是真要老板拍板。

## 1.0.1 (2026-10-28)

- 停用 / 卸载运营中心时自动演示的定时器没清掉、后台还在下令：激活后段整体重写清理清单，把前面登记的「停自动演示」冲掉了，改为追加。

## 1.0.0 (2026-10-22)

- 首版。8 个部门（`legion-*`）以方案包装在任意机器上，一台机器可承载多个；主控经集群通道 `config.set` 把部门装到员工机、`config.get` / `status.report` 回读装机与负载。
- AI 总经理判定（模型要 JSON，逐条校验，失败 / 通道错误回落关键词规则）→ 计划（命中部门常用工作流则展开）→ 按负载派 `worker.run` 并发执行 → 跨部门交接带上游产物 → 汇总 → 钱 / 签约 / 对外发布 / 录用 / 重大事项进老板待办，可批准或带意见驳回重做。
- 指挥大屏：点「启动 Web」在局域网起服务（默认 8240，被占顺延，访问口令），`/` 大屏、`/remote` 手机遥控、SSE 实时推送、断线重连；可在选定显示器全屏打开。
- 公司档案：默认北京泰途科技有限公司（标志用 App logo），可改；演示模式隐藏真实名称、例行事务 9 条、导演台（4 个内置剧本、暂停 / 重置、录制回放）、公司能力地图（39 项，按代码估计）。
- 子机打开本方案：显示本机承载的部门与主控派来的正在执行的任务。
- 同日补充：机器列表只算员工机；接收员工机回传的执行阶段（宿主 task.progress）并显示员工机 status.report 里的部门任务；
  勾选承载后员工机真正安装部门方案包（L3，宿主 legion.install）；宿主工作流页的集群工作流运行进大屏动态（E1）；按部门输出上限，剧本可用 legionConfig 按部门指定模型与输出上限（D7）；现场新建部门（L11：一句话 AI 起草，只能用已装部门的角色，人确认后保存，可分配到机器、按关键词派活）；大屏动画节点池修复：复用时清掉旧属性（旧的发光滤镜会带到下一次）、突发后收缩，加速长跑实测 60 帧、堆与节点数不随任务数增长（S9）；
  大屏部门节点 / 军团营地显示工作台细步骤（LG7 / HR7：法务逐条审查、人事筛选 37/100，主控本机 + 员工机 status.report）；
  大屏 / 遥控地址二维码（自写编码器，与 npm qrcode 逐模块一致）、大屏「军团营地」视图（V 键）；
  演示公司资料包（虚构「示例科技」，开启后各部门可引用）；来信文件夹（.eml / .txt / .md 自动成为来信任务）与公司邮箱来信（宿主 IMAP 收件箱）；
  待拍板 / 例行办完的系统通知（可同时发到老板 IM，需宿主 imRunLink.pushToImOwner）；任务产出导出为带公司抬头的 Word；剧本调优表；成本看板（演示口径估算）；
  部门专用模型与 key（L12，派往员工机的步骤带本次专用凭据，需宿主 2026-10-22 起）；OPC 考卷 39 题（作答、按检查点打分、导出覆盖率报告，含缺口排序与已知缺口）；能力地图中法务 / 人事 / 投诉 5 项状态更新。
