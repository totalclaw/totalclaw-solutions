# 海外广告投放工作台 更新日志

## 2.0.5 (2026-11-27)

- 生成的视频统一用中文：分镜的运镜提示词、字幕、TTS 旁白都写简体中文，不再随界面语言变，也不再带阿语副字幕（阿语标题只用于投放到平台的文案）。
- 「运镜提示」不再要求英文（豆包 Seedance 原生理解中文提示词），模型未按时返回时的兜底运镜模板也改为中文。
- 分镜提示词里每个镜头可单独选「首帧参考图」或「不用参考图（纯文生视频）」：选了图就是图生视频，第一帧就是这张图（品牌 logo 等必须原样出现的画面靠它）。
- 配合 App 侧改动：动态视频按「设置 → 媒体模型」里的默认视频引擎出片（选了豆包 Seedance 就直连方舟），fal 账号失效时自动换通道；动态视频也会把中文字幕烧进画面。
