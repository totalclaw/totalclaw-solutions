# 阿联酋广告代投放工作台

- id：`workbench-global-ads`
- 分类：UAE 增长
- 类型：workbench
- 入口路由：`/workbenches/global-ads`
- 依赖：`kit-automation-ops`、`workbench-charity-content`

Facebook、Instagram、Google Ads 与 YouTube 全链路投放、复盘和账户优化。

面向中东市场的全链路代投放：连接 Facebook、Instagram、Google Ads 与 YouTube 账户，从素材成片、按平台画幅适配、真实上架发布到投放复盘与账户优化，一个工作台全部完成。

## 安装

```bash
npm run tcsol -- install workbench-global-ads
```

qiye-app 中按 id `workbench-global-ads` 或名称「阿联酋广告代投放工作台」安装；已安装后随方案仓库发布自动升级，用户数据（`global-ads-run-state.json`、`ads-slideshow/`）不受影响。

本方案代码引用了 23 个宿主模块、13 个 npm 包，明细见 `origin.json`。
