# AI 客户问题与方案报告数字员工

- id：`workbench-advisory-report`
- 分类：客户咨询
- 类型：workbench
- 入口路由：`/workbenches/advisory-report`

邮件、网页表单工单与 WhatsApp 三渠道统一收件，检索获准来源后产出简短回复与七段咨询报告。

邮件、网页表单工单与 WhatsApp 三渠道统一收件，AI 只检索获准来源，先给客户简短回复稳住时效，再产出结构化的七段咨询报告供顾问定稿发出。
